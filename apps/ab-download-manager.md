# AB Download Manager

- 项目主页：https://github.com/amir1376/ab-download-manager（Apache-2.0 许可）
- 作用：IDM免费平替。分段加速下载；队列 · 定时下载；浏览器扩展 · 多主题。
- 支持系统：Windows / macOS（部分还有 Linux、手机版）

## 下载渠道（按优先级）

1. 官网：https://abdownloadmanager.com
2. GitHub Releases：https://github.com/amir1376/ab-download-manager/releases/latest

按系统选择文件（文件名会随版本变化，以 Releases 页面为准）：

| 系统 | 参考文件名 |
|---|---|
| Windows | ABDownloadManager_1.11.1_windows_arm64.exe、ABDownloadManager_1.11.1_windows_arm64.exe.md5、ABDownloadManager_1.11.1_windows_arm64.zip |
| Mac 苹果芯片 | ABDownloadManager_1.11.1_mac_arm64.dmg |
| Mac Intel | ABDownloadManager_1.11.1_mac_x64.dmg |

## 安装步骤

- Windows：运行安装包按提示安装；免安装版解压后直接打开。
- macOS：打开 `.dmg`，把应用拖进「应用程序」。

## 验证方法

- AB Download Manager 能正常打开主界面。

## 常见问题

- **Windows 提示“Windows 已保护你的电脑”：** 确认文件来自上面的官方渠道后，点「更多信息 → 仍要运行」。执行前先告诉用户原因。
- **macOS 提示无法验证开发者：** 到「系统设置 → 隐私与安全性」点击「仍要打开」。执行前先告诉用户原因。
- 只下载你有权获取的内容。
