# Anki

- 项目主页：https://github.com/ankitects/anki
- 作用：按遗忘曲线背单词。间隔重复 · 智能排复习；图文音频卡片；海量共享卡组。
- 支持系统：Windows / macOS（部分还有 Linux、手机版）

## 下载渠道（按优先级）

1. 官网：https://apps.ankiweb.net
2. GitHub Releases：https://github.com/ankitects/anki/releases/latest

按系统选择文件（文件名会随版本变化，以 Releases 页面为准）：

| 系统 | 参考文件名 |
|---|---|
| Windows | anki-26.09.3-win-arm64.msi、anki-26.09.3-win-x64.msi |
| Mac 苹果芯片 | anki-26.09.3-mac-apple.dmg |
| Mac Intel | anki-26.09.3-mac-intel.dmg |

## 安装步骤

- Windows：运行安装包按提示安装；免安装版解压后直接打开。
- macOS：打开 `.dmg`，把应用拖进「应用程序」。

## 验证方法

- Anki 能正常打开主界面。

## 常见问题

- **Windows 提示“Windows 已保护你的电脑”：** 确认文件来自上面的官方渠道后，点「更多信息 → 仍要运行」。执行前先告诉用户原因。
- **macOS 提示无法验证开发者：** 到「系统设置 → 隐私与安全性」点击「仍要打开」。执行前先告诉用户原因。
- 电脑版和安卓版免费，苹果手机版是官方收费应用。
