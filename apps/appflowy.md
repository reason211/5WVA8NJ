# AppFlowy

- 项目主页：https://github.com/AppFlowy-IO/AppFlowy（AGPL-3.0 许可）
- 作用：Notion开源平替。文档 · 看板 · 表格 · 日历；AI 写作助手；本地优先 · 可自建同步。
- 支持系统：Windows / macOS（部分还有 Linux、手机版）

## 下载渠道（按优先级）

1. 官网：https://appflowy.com
2. GitHub Releases：https://github.com/AppFlowy-IO/AppFlowy/releases/latest

按系统选择文件（文件名会随版本变化，以 Releases 页面为准）：

| 系统 | 参考文件名 |
|---|---|
| Windows | AppFlowy-0.14.10-windows-x86_64.exe、AppFlowy-0.14.10-windows-x86_64.zip |
| Mac 苹果芯片 | AppFlowy-0.14.10-macos-universal.dmg、AppFlowy-0.14.10-macos-universal.zip |

## 安装步骤

- Windows：运行安装包按提示安装；免安装版解压后直接打开。
- macOS：打开 `.dmg`，把应用拖进「应用程序」。

## 验证方法

- AppFlowy 能正常打开主界面。

## 常见问题

- **Windows 提示“Windows 已保护你的电脑”：** 确认文件来自上面的官方渠道后，点「更多信息 → 仍要运行」。执行前先告诉用户原因。
- **macOS 提示无法验证开发者：** 到「系统设置 → 隐私与安全性」点击「仍要打开」。执行前先告诉用户原因。
