# BCUninstaller

- 项目主页：https://github.com/Klocman/Bulk-Crap-Uninstaller（Apache-2.0 许可）
- 作用：流氓软件批量卸干净。批量卸载；清理残留；商店应用 · Steam 也能管。
- 支持系统：仅 Windows（个别也支持 Linux）
- **注意：** 这款软件不支持 macOS。用户是 Mac 时，如实说明并推荐清单里支持 Mac 的软件，不要尝试安装。

## 下载渠道（按优先级）

1. 官网：https://www.bcuninstaller.com/
2. GitHub Releases：https://github.com/Klocman/Bulk-Crap-Uninstaller/releases/latest

按系统选择文件（文件名会随版本变化，以 Releases 页面为准）：

| 系统 | 参考文件名 |
|---|---|
| Windows | BCUninstaller_6.3.0_net8.0-windows10.0.18362.0.zip、BCUninstaller_6.3.0_setup.exe |

## 安装步骤

- Windows：运行安装包按提示安装；免安装版解压后直接打开。
- macOS：打开 `.dmg`，把应用拖进「应用程序」。

## 验证方法

- BCUninstaller 能正常打开主界面。

## 常见问题

- **Windows 提示“Windows 已保护你的电脑”：** 确认文件来自上面的官方渠道后，点「更多信息 → 仍要运行」。执行前先告诉用户原因。
- **macOS 提示无法验证开发者：** 到「系统设置 → 隐私与安全性」点击「仍要打开」。执行前先告诉用户原因。
