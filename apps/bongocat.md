# BongoCat

- 项目主页：https://github.com/ayangweb/BongoCat（Apache-2.0 许可）
- 作用：跟你一起敲键盘的桌面猫。键盘鼠标手柄都跟着动；可换 Live2D 模型；离线运行 · 不收集数据。
- 支持系统：Windows / macOS（部分还有 Linux、手机版）

## 下载渠道（按优先级）

1. GitHub Releases：https://github.com/ayangweb/BongoCat/releases/latest

按系统选择文件（文件名会随版本变化，以 Releases 页面为准）：

| 系统 | 参考文件名 |
|---|---|
| Windows | BongoCat_2.3.1_x64.exe |
| Mac 苹果芯片 | BongoCat-2.3.1-aarch64.dmg |
| Mac Intel | BongoCat-2.3.1-x64.dmg |

## 安装步骤

- Windows：运行安装包按提示安装；免安装版解压后直接打开。
- macOS：打开 `.dmg`，把应用拖进「应用程序」。

## 验证方法

- BongoCat 能正常打开主界面。

## 常见问题

- **Windows 提示“Windows 已保护你的电脑”：** 确认文件来自上面的官方渠道后，点「更多信息 → 仍要运行」。执行前先告诉用户原因。
- **macOS 提示无法验证开发者：** 到「系统设置 → 隐私与安全性」点击「仍要打开」。执行前先告诉用户原因。
