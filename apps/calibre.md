# calibre

- 项目主页：https://github.com/kovidgoyal/calibre （GPL-3.0），官网 https://calibre-ebook.com ，使用手册 https://manual.calibre-ebook.com
- 作用：免费开源的电子书管理软件。管理书库（按作者、标签、系列等分类，搜索）、自带阅读器（支持主流电子书格式）、格式转换（EPUB、MOBI、AZW3、PDF 等互转）、电子书编辑器（编辑 EPUB / Kindle 格式并实时预览）、联网获取书籍封面和简介、内容服务器（用浏览器在线浏览、阅读和下载自己书库里的书）。
- 支持系统：Windows、macOS、Linux。
- 界面支持简体中文。

## 下载渠道（按优先级）

- 官网下载页：https://calibre-ebook.com/download （国内可直接访问）
- GitHub Releases：https://github.com/kovidgoyal/calibre/releases/latest
- 写作本教程时的版本是 9.17.0，文件名以下载页为准：

| 系统 | 文件 |
|---|---|
| Windows 64 位 | `calibre-64bit-<版本>.msi`（安装版）或 `calibre-portable-installer-<版本>.exe`（便携版） |
| macOS | `calibre-<版本>.dmg` |

## 安装步骤

- **Windows：** 双击 `.msi`，按提示点「下一步」完成安装（安装时 Windows 可能弹出用户账户控制，请用户自己确认）。装完在开始菜单或桌面打开 calibre。
- **macOS：** 打开 `.dmg`，把 calibre.app 拖进「应用程序」。首次打开如果提示无法验证开发者，到「系统设置 → 隐私与安全性」点「仍要打开」。执行前先告诉用户原因。
- 首次打开会出现「欢迎向导」：语言选「中文（简体）」，书库位置用默认（用户文档下的 Calibre Library）即可，电子书阅读器设备不确定就选「通用」，然后点「完成」。

## 使用方法（告诉用户）

1. 点工具栏「添加书籍」，选电脑里的电子书，书就进了书库；左侧按作者、标签等分类，顶部搜索框直接搜。
2. 双击一本书，用自带阅读器打开阅读。
3. 选中书点「转换书籍」，在右上角选输出格式（如 EPUB、MOBI、AZW3、PDF），点「确定」；转换好的文件在书的详情里点「格式」打开。
4. 选中书点「编辑元数据」→「下载元数据」，可以联网补全封面和简介。
5. 「编辑书籍」可以修改 EPUB 文字和样式，右侧实时预览。
6. 「连接/共享」→「启动内容服务器」，同一网络下用手机或其他电脑的浏览器打开显示的地址，就能在线浏览、阅读和下载书库里的书。

## 验证方法

- 能打开 calibre 主界面，看到书库列表和顶部工具栏。

## 常见问题

- **界面是英文：** 「Preferences（首选项）」→「Look & feel（外观）」→ 界面语言选「中文（简体）」，重启 calibre。
- **内容服务器打不开：** 首次启动时 Windows 防火墙可能询问是否允许 calibre 访问网络，需要用户自己确认「允许」。
- calibre 本身不提供任何电子书内容，请只管理和转换你有权使用的书籍；带 DRM 的书无法转换。
