# Chatbox

- 项目主页：https://github.com/chatboxai/chatbox（GPL-3.0 许可）
- 作用：干净好用的AI客户端。接入各家大模型；记录存在本地；电脑手机都能用。
- 支持系统：Windows / macOS（部分还有 Linux、手机版）

## 下载渠道（按优先级）

1. 官网：https://chatboxai.app?utm_medium=github
2. GitHub Releases：https://github.com/chatboxai/chatbox/releases/latest

## 安装步骤

- Windows：运行安装包按提示安装；免安装版解压后直接打开。
- macOS：打开 `.dmg`，把应用拖进「应用程序」。

## 验证方法

- Chatbox 能正常打开主界面。

## 常见问题

- **Windows 提示“Windows 已保护你的电脑”：** 确认文件来自上面的官方渠道后，点「更多信息 → 仍要运行」。执行前先告诉用户原因。
- **macOS 提示无法验证开发者：** 到「系统设置 → 隐私与安全性」点击「仍要打开」。执行前先告诉用户原因。
- 使用云端模型需要自己准备对应服务的 API 密钥。
