# Cherry Studio

- 项目主页：https://github.com/CherryHQ/cherry-studio（AGPL-3.0 许可）
- 作用：一个窗口用遍各家AI。多模型一个窗口 · 同题对比；本地知识库；画图 · 智能体。
- 支持系统：Windows / macOS（部分还有 Linux、手机版）

## 下载渠道（按优先级）

1. 官网：https://cherryai.com
2. GitHub Releases：https://github.com/CherryHQ/cherry-studio/releases/latest

按系统选择文件（文件名会随版本变化，以 Releases 页面为准）：

| 系统 | 参考文件名 |
|---|---|
| Windows | Cherry-Studio-2.1.7-win-arm64-portable.exe、Cherry-Studio-2.1.7-win-arm64-setup.exe、Cherry-Studio-2.1.7-win-x64-portable.exe |
| Mac 苹果芯片 | Cherry-Studio-2.1.7-mac-arm64.dmg、Cherry-Studio-2.1.7-mac-arm64.zip |
| Mac Intel | Cherry-Studio-2.1.7-mac-x64.dmg |

## 安装步骤

- Windows：运行安装包按提示安装；免安装版解压后直接打开。
- macOS：打开 `.dmg`，把应用拖进「应用程序」。

## 验证方法

- Cherry Studio 能正常打开主界面。

## 常见问题

- **Windows 提示“Windows 已保护你的电脑”：** 确认文件来自上面的官方渠道后，点「更多信息 → 仍要运行」。执行前先告诉用户原因。
- **macOS 提示无法验证开发者：** 到「系统设置 → 隐私与安全性」点击「仍要打开」。执行前先告诉用户原因。
- 使用云端模型需要自己准备对应服务的 API 密钥。
