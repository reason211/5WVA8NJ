# EarTrumpet

- 项目主页：https://github.com/File-New-Project/EarTrumpet（MIT 许可条款，LICENSE 另列三家被排除的公司；个人使用不受影响），官网 https://eartrumpet.app
- 作用：Windows 音量控制工具。任务栏右下角多一个小喇叭：每个正在出声的软件一根独立滑块和跳动的音量条；可以给单个软件指定播放设备（比如音乐走音箱、语音进耳机）；右键菜单直接切换默认播放设备；鼠标停在图标上滚动滚轮调总音量；可配置快捷键，界面有简体中文。
- 支持系统：Windows 10（1803 及以上）、Windows 11。
- **注意：** 这款软件只支持 Windows。用户是 Mac 时，如实说明并推荐清单里支持 Mac 的软件，不要尝试安装。

## 下载渠道（按优先级）

1. 微软商店（README 指定的官方渠道，国内可直接访问，免费）：https://apps.microsoft.com/detail/9NBLGGH516XP ，或在微软商店里搜索「EarTrumpet」，发布者应为 File-New-Project。
2. WinGet（系统自带的包管理器，安装包来自官方 install.eartrumpet.app）：`winget install --id File-New-Project.EarTrumpet -e`
3. 也可以用 WinGet 走微软商店源：`winget install 9NBLGGH516XP -s msstore`

> GitHub Releases 页面上的 1.x 版本是 2016 年的旧版，不要使用。

## 安装步骤

1. 优先用微软商店：打开上面的商店页面点「获取 / 安装」，安装为当前用户，不需要管理员权限。
2. 没有商店时用第 2 或第 3 条 WinGet 命令安装；命令要求同意协议时，先把协议名称告诉用户再继续。
3. 安装完成后，在开始菜单打开 EarTrumpet；任务栏右下角会出现一个新的小喇叭图标。图标被收进「^」隐藏区时，告诉用户可以把它拖到任务栏上常驻。
4. 告诉用户怎么用：
   - 左键小喇叭：每个出声的软件一根滑块，拖动只改这个软件的音量；
   - 想让某个软件走另一个设备：在面板（或音量合成器）里右键这个软件、或选中后按空格，弹出的小面板里点「指定此应用的播放设备」按钮，再选设备；
   - 右键小喇叭：菜单里直接点要用的播放设备，切换默认设备；也能打开音量合成器和设置；
   - 鼠标停在小喇叭上滚动滚轮，可以调总音量（默认开启，可在设置里关）。
5. 想代替系统自带的音量图标：在「设置 → 个性化 → 任务栏 → 其他系统托盘图标」里把系统的「音量」关掉（只改显示，不影响声音）。执行前先问用户是否需要。

## 验证方法

- 开始菜单能搜到并打开 EarTrumpet，任务栏右下角出现它的小喇叭；左键点开能看到正在出声的软件各自的滑块。

## 常见问题

- **点开面板里看不到某个软件：** 只有正在出声（或刚出过声）的软件才会出现，先让它播放一下声音。
- **指定播放设备后没生效：** 关掉并重新打开这个软件；EarTrumpet 启动时也会重新设置一次。
- **安全软件误报：** 只使用上面的官方渠道；确认来源无误后再按安全软件提示放行，执行前先告诉用户原因。
- **卸载：** 在「设置 → 应用 → 已安装的应用」里找到 EarTrumpet 卸载，或 `winget uninstall --id File-New-Project.EarTrumpet -e`。
