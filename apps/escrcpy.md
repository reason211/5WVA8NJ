# Escrcpy

- 项目主页：https://github.com/viarotel-org/escrcpy（Apache-2.0 许可）
- 作用：安卓投屏到电脑 键鼠直接操控。低延迟投屏 · 有线无线都行；键盘映射 · 触屏绑按键；多台手机一起控制。
- 支持系统：Windows / macOS（部分还有 Linux、手机版）

## 下载渠道（按优先级）

1. 官网：https://viarotel.eu.org/
2. GitHub Releases：https://github.com/viarotel-org/escrcpy/releases/latest

按系统选择文件（文件名会随版本变化，以 Releases 页面为准）：

| 系统 | 参考文件名 |
|---|---|
| Windows | Escrcpy-3.3.1-win-arm64.zip、Escrcpy-3.3.1-win-portable-arm64.exe、Escrcpy-3.3.1-win-portable-x64.exe |
| Mac 苹果芯片 | Escrcpy-3.3.1-mac-arm64.dmg、Escrcpy-3.3.1-mac-arm64.zip |
| Mac Intel | Escrcpy-3.3.1-mac-x64.dmg |

## 安装步骤

- Windows：运行安装包按提示安装；免安装版解压后直接打开。
- macOS：打开 `.dmg`，把应用拖进「应用程序」。

## 验证方法

- Escrcpy 能正常打开主界面。

## 常见问题

- **Windows 提示“Windows 已保护你的电脑”：** 确认文件来自上面的官方渠道后，点「更多信息 → 仍要运行」。执行前先告诉用户原因。
- **macOS 提示无法验证开发者：** 到「系统设置 → 隐私与安全性」点击「仍要打开」。执行前先告诉用户原因。
