# File Converter

- 项目主页：https://github.com/Tichau/FileConverter（GPL-3.0 许可）
- 作用：右键一点就转格式。在文件上右键选目标格式，文档、图片、音频、视频直接转换或压缩；一次选多个文件批量转。
- 支持系统：仅 Windows
- **注意：** 这款软件只支持 Windows。用户是 Mac 时，如实说明并推荐清单里支持 Mac 的软件，不要尝试安装。

## 下载渠道（按优先级）

1. 官网：https://file-converter.io/
2. GitHub Releases：https://github.com/Tichau/FileConverter/releases/latest

按系统选择文件（文件名会随版本变化，以 Releases 页面为准）：

| 系统 | 参考文件名 |
|---|---|
| Windows | FileConverter-2.2-x64-setup.msi |

## 安装步骤

- Windows：运行 `.msi` 安装包，按提示安装。安装后不需要单独打开程序，在资源管理器里右键文件就能看到「File Converter」菜单。

## 验证方法

- 在任意图片或文档上右键，菜单里出现「File Converter」，并能选择目标格式。
- 如果右键菜单没出现，重启资源管理器或重启电脑后再看。

## 常见问题

- **Windows 提示“Windows 已保护你的电脑”：** 确认文件来自上面的官方渠道后，点「更多信息 → 仍要运行」。执行前先告诉用户原因。
- **Windows 11 右键菜单里找不到：** 先点「显示更多选项」，在完整菜单里找「File Converter」。
