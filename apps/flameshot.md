# Flameshot

- 项目主页：https://github.com/flameshot-org/flameshot（GPL-3.0 许可）
- 作用：截图同时标注打码。箭头 · 方框 · 文字；一键马赛克；贴图钉桌面。
- 支持系统：Windows / macOS（部分还有 Linux、手机版）

## 下载渠道（按优先级）

1. 官网：https://flameshot.org
2. GitHub Releases：https://github.com/flameshot-org/flameshot/releases/latest

按系统选择文件（文件名会随版本变化，以 Releases 页面为准）：

| 系统 | 参考文件名 |
|---|---|
| Windows | Flameshot-14.0.0-win64.msi、flameshot-14.0.0-win64.zip |
| Mac 苹果芯片 | Flameshot-14.0-macos-arm64.dmg |
| Mac Intel | Flameshot-14.0-macos-intel.dmg |

## 安装步骤

- Windows：运行安装包按提示安装；免安装版解压后直接打开。
- macOS：打开 `.dmg`，把应用拖进「应用程序」。

## 验证方法

- Flameshot 能正常打开主界面。

## 常见问题

- **Windows 提示“Windows 已保护你的电脑”：** 确认文件来自上面的官方渠道后，点「更多信息 → 仍要运行」。执行前先告诉用户原因。
- **macOS 提示无法验证开发者：** 到「系统设置 → 隐私与安全性」点击「仍要打开」。执行前先告诉用户原因。
