# Heroic

- 项目主页：https://github.com/Heroic-Games-Launcher/HeroicGamesLauncher（GPL-3.0 许可）
- 作用：Epic GOG游戏一个启动器。Epic · GOG · 亚马逊；云存档同步；兼容层玩 Windows 游戏。
- 支持系统：Windows / macOS（部分还有 Linux、手机版）

## 下载渠道（按优先级）

1. 官网：https://heroicgameslauncher.com
2. GitHub Releases：https://github.com/Heroic-Games-Launcher/HeroicGamesLauncher/releases/latest

按系统选择文件（文件名会随版本变化，以 Releases 页面为准）：

| 系统 | 参考文件名 |
|---|---|
| Windows | Heroic-2.22.4-Portable-arm64.exe、Heroic-2.22.4-Portable-x64.exe、Heroic-2.22.4-Setup-arm64.exe |
| Mac 苹果芯片 | Heroic-2.22.4-macOS-arm64.dmg、Heroic-2.22.4-macOS-arm64.zip |
| Mac Intel | Heroic-2.22.4-macOS-x64.dmg |

## 安装步骤

- Windows：运行安装包按提示安装；免安装版解压后直接打开。
- macOS：打开 `.dmg`，把应用拖进「应用程序」。

## 验证方法

- Heroic 能正常打开主界面。

## 常见问题

- **Windows 提示“Windows 已保护你的电脑”：** 确认文件来自上面的官方渠道后，点「更多信息 → 仍要运行」。执行前先告诉用户原因。
- **macOS 提示无法验证开发者：** 到「系统设置 → 隐私与安全性」点击「仍要打开」。执行前先告诉用户原因。
- 只运行你已拥有的正版游戏。
