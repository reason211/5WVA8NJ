# Image Toolbox

- 项目主页：https://github.com/T8RIN/ImageToolbox （Apache-2.0）
- 作用：免费开源的安卓图片工具，支持抠图、涂鸦、文字与拼图、滤镜、AI 图片放大和文件加密。
- 支持系统：Android；电脑用于下载安装包，应用在安卓手机上运行。

## 下载渠道

1. 官方稳定版：https://github.com/T8RIN/ImageToolbox/releases/latest
2. F-Droid：https://f-droid.org/packages/ru.tech.imageresizershrinker/

## 下载与安装

1. 打开官方稳定版页面，找到最新版本的 Assets。通用开源版文件名为 `image-toolbox-版本号-foss-universal.apk`；不要选 source code 或预发布版。
2. 将 APK 下载到电脑的下载文件夹，告诉用户完整路径。不要在电脑上运行 APK。
3. 用户将 APK 传到安卓手机，在手机上点开文件并按系统提示完成安装。只有用户明确同意、手机已通过 USB 连接并授权调试时，才可用 `adb install <APK路径>` 安装。
4. 安装后在手机应用列表打开 Image Toolbox，选择照片，即可使用编辑工具。

## 验证与提示

- 在电脑上确认 APK 文件存在且大小非零；手机安装后的验证是打开 Image Toolbox 并看到工具列表。
- 如果系统提示安装来源或安全风险，请用户核实来源并自行决定；不要关闭系统安全防护或绕过警告。
- 部分 AI 功能使用时可能需要下载模型，按应用内提示操作。
