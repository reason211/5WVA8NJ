# Kando

- 项目主页：https://github.com/kando-menu/kando（MIT 许可）
- 作用：跨平台高颜值圆形技能轮盘菜单。按住快捷键呼出轮盘，鼠标一甩直达常用软件、网页、快捷键和系统控制；多层嵌套、主题丰富。
- 支持系统：Windows / macOS / Linux

## 下载渠道（按优先级）

1. GitHub Releases：https://github.com/kando-menu/kando/releases/latest
2. 官网：https://kando.menu

按系统选择安装包（以 Releases 页面为准）：
- Windows：下载 `.exe` 安装包运行；或便携版解压运行。
- macOS：下载 `.dmg`，拖入「应用程序」。
- Linux：下载 `.AppImage` 或 `.deb`。

## 安装步骤

- Windows：双击安装包按提示完成安装。
- macOS：打开 `.dmg`，把 Kando 拖进「应用程序」，首次启动按提示授予辅助功能权限。
- Linux：赋予 `.AppImage` 可执行权限后直接运行。

## 验证方法

- 启动 Kando，按下默认快捷键（如 Ctrl + 空格 或自定义快捷键），屏幕鼠标指针处应立即弹出圆形技能轮盘菜单，甩动鼠标能高亮并触发对应项目。

## 常见问题

- **Windows 提示未识别的应用：** 确认来自官方 Releases，点击「更多信息 → 仍要运行」。
- **macOS 无法呼出轮盘：** 在「系统设置 → 隐私与安全性 → 辅助功能」中勾选允许 Kando。
