# Krita

- 项目主页：https://github.com/KDE/krita（GPL-3.0 许可）
- 作用：免费专业绘画软件。上百种笔刷；图层 · 动画时间轴；数位板压感。
- 支持系统：Windows / macOS（部分还有 Linux、手机版）

## 下载渠道（按优先级）

1. 官网：https://invent.kde.org/graphics/krita
2. 官网下载页：https://krita.org/zh-cn/download/
3. GitHub Releases：https://github.com/KDE/krita/releases/latest

## 安装步骤

- Windows：运行安装包按提示安装；免安装版解压后直接打开。
- macOS：打开 `.dmg`，把应用拖进「应用程序」。

## 验证方法

- Krita 能正常打开主界面。

## 常见问题

- **Windows 提示“Windows 已保护你的电脑”：** 确认文件来自上面的官方渠道后，点「更多信息 → 仍要运行」。执行前先告诉用户原因。
- **macOS 提示无法验证开发者：** 到「系统设置 → 隐私与安全性」点击「仍要打开」。执行前先告诉用户原因。
