# LinearMouse

- 项目主页：https://github.com/linearmouse/linearmouse（MIT 许可），官网 https://linearmouse.app
- 作用：Mac 鼠标和触控板独立调节工具。把外接鼠标和电脑触控板分开设置，保持触控板自然滚动的同时反转鼠标滚轮、关闭系统指针加速度让鼠标不飘、自定义滚动速度与侧键返回前进。
- 支持系统：仅 macOS
- **注意：** 这款软件只支持 macOS。用户是 Windows 或 Linux 时，如实说明，不要尝试安装。

## 下载渠道（按优先级）

1. GitHub Releases：https://github.com/linearmouse/linearmouse/releases/latest
   - `LinearMouse.dmg`
2. 官网下载页：https://linearmouse.app
3. macOS 也可用 Homebrew：`brew install --cask linearmouse`

## 安装步骤

- 打开下载的 `LinearMouse.dmg`，把 `LinearMouse.app` 拖进「应用程序」。
- 首次打开按提示到「系统设置 → 隐私与安全性 → 辅助功能」里开启 LinearMouse 权限，之后即可按设备分别设置滚轮方向、指针速度与侧键功能。

## 验证方法

- 菜单栏出现 LinearMouse 图标，打开设置界面后能分别选择外接鼠标和触控板，并单独开关「反转滚动（Reverse scrolling）」或「禁用指针加速（Disable pointer acceleration）」。

## 常见问题

- **macOS 提示无法验证开发者：** 到「系统设置 → 隐私与安全性」点击「仍要打开」。执行前先告诉用户原因。
- **反转滚动或侧键不生效：** 到「系统设置 → 隐私与安全性 → 辅助功能」里确认已勾选 LinearMouse。
