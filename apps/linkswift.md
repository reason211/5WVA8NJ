# LinkSwift（网盘直链下载助手）

- 项目主页：https://github.com/hmjz100/LinkSwift（AGPL-3.0 许可）
- 作用：浏览器用户脚本。在百度网盘 / 阿里云盘 / 中国移动云盘 / 天翼云盘 / 迅雷云盘 / 光鸭云盘 / 夸克网盘 / UC 网盘 / 123 云盘的网页里增加「下载助手」，勾选文件后获取下载链接，可交给浏览器自带下载、IDM、Aria2、比特彗星、AB Download Manager 等下载器，也能一次复制全部链接。
- 支持：电脑上的 Chrome（≥76）/ Edge（≥88）等支持用户脚本的浏览器。
- **边界（告诉用户）：** 项目说明链接来自各网盘公开接口，**不承诺也不实现破解限速**；下载速度取决于网盘策略和用户网络，不要宣传“加速”“破解”。只下载自己有权下载的文件，遵守各网盘用户协议。不安装作者仓库里的「会员青春版」等其它扩展脚本。

## 安装步骤

1. **确认浏览器：** 找到用户常用的 Chrome 或 Edge；没有就先说明并取得同意再安装。
2. **安装用户脚本管理器（二选一，来自浏览器官方扩展商店）：**
   - 篡改猴 Tampermonkey：Chrome 应用商店 / Edge 加载项商店搜索「Tampermonkey」。
   - 脚本猫 ScriptCat：Chrome 应用商店 / Edge 加载项商店搜索「ScriptCat」。
   - 新版 Chrome / Edge 需要在扩展详情页打开「允许用户脚本」（或在扩展管理页开启「开发者模式」），否则脚本不会运行。执行前告诉用户原因。
3. **安装 LinkSwift 脚本（正式版，任选一个官方源）：**
   - GitHub：https://github.com/hmjz100/LinkSwift/raw/main/（改）网盘直链下载助手.user.js
   - 脚本猫（国内）：https://scriptcat.org/scripts/code/1604/LinkSwift.user.js
   用浏览器打开链接，在脚本管理器弹出的安装页确认「安装」。只用这两个来源，不从其它网站下载。
4. **可选下载器：** 用户已有 IDM / Aria2 / 比特彗星 / AB Download Manager 就复用；没有时可以先用浏览器自带下载，需要再按用户意愿安装，不默认安装第三方下载器。

## 首次使用（告诉用户）

1. 打开对应网盘的网页版并登录自己的账号（账号密码由用户本人输入，不代为保存）。
2. 勾选文件，点击页面上新增的「下载助手」，选择「API 下载」等方式获取链接；可点链接下载、推送到已配置的下载器，或复制全部链接。
3. 百度网盘首次使用会按提示进行官方授权；授权信息只保存在用户自己的浏览器里。

## 验证方法

- 脚本管理器的脚本列表里能看到 LinkSwift 且为启用状态。
- 打开任一支持的网盘网页、勾选文件后，工具栏出现「下载助手」按钮。

## 常见问题

- **看不到下载助手按钮：** 确认脚本已启用、扩展已打开「允许用户脚本」，然后刷新网盘页面。
- **链接获取失败：** 网盘接口变化较快，到脚本管理器里检查更新；仍失败请到项目 Issues 反馈。
- **速度没变快：** 属正常情况。速度由网盘策略和网络决定，本项目不破解限速。
