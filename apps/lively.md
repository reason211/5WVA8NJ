# Lively Wallpaper：免费动态壁纸

- 项目主页：https://github.com/rocksdanister/lively（GPL-3.0 许可）
- 作用：把视频、网页、动画设为 Windows 动态桌面。全屏打游戏或窗口挡住桌面时自动暂停，不占性能。
- 支持系统：**仅 Windows 10（1809 及以上）和 Windows 11。** 其他系统请改装清单里的其他软件。

## 下载渠道（按优先级）

1. **微软商店（官方推荐，不会被 SmartScreen 拦截）：** 打开 Microsoft Store 搜索「Lively Wallpaper」，或打开 https://apps.microsoft.com/detail/9NTM2QC6QWS7
2. GitHub Releases 安装包：https://github.com/rocksdanister/lively/releases/latest

## 安装步骤

1. 优先用微软商店点击「获取」安装。
2. 安装后从开始菜单打开 Lively Wallpaper。
3. 在 Lively 的壁纸库里选一个自带壁纸，点击设为壁纸。

## 验证方法

- 桌面背景变成动态壁纸，桌面图标仍然可以正常点击。

## 常见问题

- **安装包被 SmartScreen 拦截：** 改用微软商店安装。
- **左上角出现黑块：** 通常是和其他修改窗口的美化工具冲突（项目 issue #2890），先关闭那类工具再试。
- 壁纸素材请使用自己有权使用的内容。
