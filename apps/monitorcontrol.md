# MonitorControl

- 项目主页：https://github.com/MonitorControl/MonitorControl（MIT 许可）
- 作用：Mac键盘调外接屏亮度。键盘调外接屏亮度；键盘调音量；多显示器一起控。
- 支持系统：仅 macOS
- **注意：** 这款软件只支持 macOS。用户是 Windows 时，如实说明，不要尝试安装。

## 下载渠道（按优先级）

1. 官网：https://monitorcontrol.app
2. GitHub Releases：https://github.com/MonitorControl/MonitorControl/releases/latest

按系统选择文件（文件名会随版本变化，以 Releases 页面为准）：

| 系统 | 参考文件名 |
|---|---|
| Mac 苹果芯片 | MonitorControl.4.4.0.dmg |

## 安装步骤

- Windows：运行安装包按提示安装；免安装版解压后直接打开。
- macOS：打开 `.dmg`，把应用拖进「应用程序」。

## 验证方法

- MonitorControl 能正常打开主界面。

## 常见问题

- **Windows 提示“Windows 已保护你的电脑”：** 确认文件来自上面的官方渠道后，点「更多信息 → 仍要运行」。执行前先告诉用户原因。
- **macOS 提示无法验证开发者：** 到「系统设置 → 隐私与安全性」点击「仍要打开」。执行前先告诉用户原因。
