# MusicFree：插件化、无广告的音乐播放器

- 项目主页：桌面版 https://github.com/maotoumao/MusicFreeDesktop ，安卓版 https://github.com/maotoumao/MusicFree（AGPL-3.0 许可）
- 作用：免费、无广告的音乐播放器。**软件本身不带任何音源**，搜索、播放、导入歌单都依靠用户自行添加的插件。请支持正版，只使用你有权收听的内容。
- 支持系统：Windows、macOS、Linux、安卓。

## 下载渠道

- 官网：https://musicfree.catcat.work
- 桌面版 GitHub Releases：https://github.com/maotoumao/MusicFreeDesktop/releases/latest

| 系统 | 文件名包含 |
|---|---|
| Windows 10 / 11 | `win32-x64-setup.exe`（安装版）或 `win32-x64-portable.zip`（免安装） |
| 较老的 Windows（如 Win7） | `win32-x64-legacy-setup.exe` |
| Mac 苹果芯片 | `darwin-arm64.dmg` |
| Mac Intel 芯片 | `darwin-x64.dmg` |
| 安卓 | 安卓版 Releases 里的 `app-universal-release.apk` |

## 安装步骤

- Windows：双击 `setup.exe` 按提示安装。
- macOS：打开 `.dmg`，把 MusicFree 拖进「应用程序」。

## 验证方法

- MusicFree 能正常打开。是否添加插件、添加哪些插件，由用户自己决定，AI 不要替用户添加任何音源插件。

## 常见问题

- **Windows 提示“Windows 已保护你的电脑”：** 确认文件来自官方渠道后，点「更多信息 → 仍要运行」。执行前先告诉用户原因。
- **macOS 提示无法验证开发者：** 到「系统设置 → 隐私与安全性」点击「仍要打开」。执行前先告诉用户原因。
