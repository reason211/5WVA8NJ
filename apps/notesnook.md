# Notesnook

- 项目主页：https://github.com/streetwriters/notesnook（GPL-3.0 许可），官网 https://notesnook.com
- 作用：端到端加密的开源笔记软件。支持富文本、Markdown、任务清单、表格、折叠大纲、数学公式、代码高亮和图片附件，支持无限条笔记和多端加密同步，所有笔记在本机先加密再上传。
- 支持系统：Windows、macOS、Linux、Android、iOS

## 下载渠道（只用官方）

1. 官网下载：https://notesnook.com/downloads
2. GitHub Releases：https://github.com/streetwriters/notesnook/releases/latest
- 发布页按系统选择：Windows 选 `notesnook_win_x64.exe`（安装版）或 `notesnook_win_x64_portable.exe`（便携版），ARM64 选 `notesnook_win_arm64.exe`；macOS Apple 芯片选 `notesnook_mac_arm64.dmg`，Intel 选 `notesnook_mac_x64.dmg`；Linux 选 `.AppImage` 或官网下载页对应包；手机端在苹果 App Store 或 Google Play 搜索「Notesnook」。不要下载 `.blockmap` 和 `.yml` 文件。

## 安装步骤

- Windows：双击安装版 `.exe` 按提示完成安装；便携版直接双击运行。
- macOS：打开 `.dmg`，把 Notesnook 拖进「应用程序」。若首次打开提示无法验证开发者，到「系统设置 → 隐私与安全性」点击「仍要打开」，执行前先向用户说明原因。
- 手机端：从官方应用商店安装后，登录同一账号即可多端自动加密同步。

## 验证方法

- Notesnook 能正常打开主界面，新建一条笔记并输入文字、插入待办或表格可正常保存。

## 常见问题

- **Windows 提示“Windows 已保护你的电脑”：** 确认文件来自上面的官方渠道后，点「更多信息 → 仍要运行」。执行前先告诉用户原因。
- **不想登录同步只本地用：** 打开软件后可直接在本地新建和编辑笔记；需要多端同步时再注册或登录账号。
