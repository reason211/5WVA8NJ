# PPSSPP

- 项目主页：https://github.com/hrydgard/ppsspp ，官网：https://www.ppsspp.org/ 。
- 作用：开源 PSP 模拟器，可在电脑或安卓设备上运行用户有权使用的 PSP 游戏数据；支持保存和恢复游戏状态、调整画面分辨率、屏幕按键及外接手柄。
- 支持 Windows、macOS、Linux 和 Android。软件本身不提供商业游戏；只使用用户拥有或获授权的游戏及存档，不代找游戏资源，不绕过版权或安全限制。

## 官方渠道

- 官方下载页：https://www.ppsspp.org/download/ 。按系统选择免费稳定版，不擅自购买 Gold 版；下载页同时提供 Windows、macOS 和 Android 官方直链。
- 项目官方稳定版及资产校验信息：https://github.com/hrydgard/ppsspp/releases/latest 。选择匹配系统和处理器的稳定版文件，不选预发布版。
- 中国区 iOS App Store 上架情况未确认，不声称可用；Android 版本由手机用户自行确认并安装。

## 安装步骤

1. 先说明将安装的软件、下载来源和目标位置，取得用户同意；识别电脑系统、处理器架构和是否已安装。保留已有游戏、存档和设置，不覆盖或删除。
2. Windows 优先取官方发布的对应架构便携 ZIP；下载后核对 GitHub 官方发布 API `https://api.github.com/repos/hrydgard/ppsspp/releases/latest` 中**同名资产**的 `digest` SHA-256，再解压至用户同意的目录。官网 ZIP 与 GitHub ZIP 可能不同，不能套用另一个文件的校验值；若无法取得可核对的官方校验信息，暂停并告知用户。确认解压路径无冲突后打开对应的 PPSSPP 程序。
3. macOS 从官网下载匹配的稳定版 DMG，核对发布者签名与系统安全检查，通过后打开并将应用拖入「应用程序」；Linux 使用与架构匹配的官方 AppImage，按 GitHub 同名资产 `digest` 核对 SHA-256 后运行。需要安装额外组件、管理员权限或更改系统设置时先征得同意。遇到签名、恶意软件或系统安全警告时停止核实，不关闭防护或绕过。
4. 确认软件真实打开并显示主界面，告诉用户实际程序位置、再次打开方法及卸载方式；未实际打开不得报告安装成功。

## 使用和验收

- 用户可在软件中选择自己有权使用的 PSP 游戏文件；也可使用项目提供的合法自制游戏和演示。不得下载或分发未授权游戏。
- 按项目说明操作游戏内保存/恢复，必要时先备份存档；可自行调整渲染分辨率、触屏按键或已连接手柄。原 PSP 存档的复制应先确认源与目标路径，不覆盖原件。
- 安卓用户如需使用，在手机上通过官方渠道取得安装包并自行决定是否安装；不要替用户关闭手机安全防护。
