# RapidRAW（GPU 加速 RAW 照片调色与影库管理）

- 项目主页：https://github.com/CyberTimon/RapidRAW （AGPL-3.0 许可），官网：https://www.getrapidraw.com
- 作用：轻量跨平台 RAW 照片无损修图软件，提供曝光、曲线、调色轮、选区蒙版、降噪、AI 2 倍超分放大、影库星级筛选和批量导出功能，修改参数不改写原片。
- 支持系统：Windows 10 / 11、macOS（Apple 芯片 / Intel）、Linux、Android

## 下载渠道（按优先级）

1. GitHub Releases：https://github.com/CyberTimon/RapidRAW/releases/latest
2. 官网下载页：https://www.getrapidraw.com

## 安装步骤

- **Windows：** 从 GitHub Releases 下载 `01_RapidRAW_v*_windows_x64.exe`（或 `.msi`，ARM64 电脑选 `windows-11-arm_arm64.exe`），双击运行安装程序按提示完成安装。
- **macOS：** 从 GitHub Releases 下载 `02_RapidRAW_v*_macos-15_aarch64.dmg`（Apple 芯片）或 `02_RapidRAW_v*_macos-15-intel_x64.dmg`（Intel 芯片），打开 `.dmg` 将 RapidRAW 拖入「应用程序」文件夹。
- **Linux / Android：** Linux 下载对应 `.AppImage`、`.deb` 或 `.rpm`；Android 下载 `04_RapidRAW_v*_android_aarch64.apk`。

## 验证方法

- 打开 RapidRAW，能够正常进入照片库视图并选择本地文件夹，点开单张照片或 RAW 文件后右侧调整面板和直方图可正常拖动预览。

## 常见问题

- **Windows 提示“Windows 已保护你的电脑”：** 确认安装包来自上面的官方渠道后，点「更多信息 → 仍要运行」。执行前先告诉用户原因。
- **macOS 提示无法验证开发者：** 到「系统设置 → 隐私与安全性」点击「仍要打开」。执行前先告诉用户原因。
