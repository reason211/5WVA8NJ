# Read Frog（浏览器双语翻译和生词复习）

上游项目：https://github.com/mengxi-ream/read-frog ；官方安装指南：https://www.readfrog.app/zh/docs/installation 。

## 安装前

先确认用户使用 Chrome、Edge 还是 Firefox。告诉用户将安装浏览器扩展，使用云翻译时，所选服务商会收到需要翻译的内容；取得同意后再继续。不要读取、索取或保存用户的密码、验证码或 API 密钥。只使用官方商店安装。

## 安装

1. 按用户使用的浏览器打开对应商店：
   - Chrome：https://chromewebstore.google.com/detail/read-frog/modkelfkcfjpgbfmnbnllalkiogfofhb
   - Edge：https://microsoftedge.microsoft.com/addons/detail/read-frog-open-source-a/cbcbomlgikfbdnoaohcjfledcoklcjbo
   - Firefox：https://addons.mozilla.org/firefox/addon/read-frog-open-ai-translator/
2. 核对项目名 Read Frog、开发者和上游链接，再通过商店的“添加”入口安装。浏览器权限确认、登录和安全验证交给用户本人处理。
3. 安装后，在浏览器扩展菜单找到 Read Frog；用户需要时将它固定到工具栏。打开一篇用户有权使用的外文网页，在插件弹窗选择目标语言，再点翻译，或使用官方默认快捷键 Alt+E。

## 翻译与复习

- 官方指南说明，Google 翻译和微软翻译不需要 API 密钥；可以先让用户选择一个可用的服务。不同服务的网络、费用和隐私条款可能不同，不承诺所有功能都免费。
- 词典、保存到笔记库等 AI 功能可以使用内置 AI 或用户自己的模型服务；需要密钥时，请用户自行在插件设置中输入。首次向外发送网页内容或启用收费服务前，说明情况并取得同意。
- 保存生词和复习卡需要登录 Read Frog。请用户自己登录，不代填账号密码或验证码。字幕支持的服务和语言以官方说明及实际界面为准。

## 验收与交付

确认 Read Frog 出现在浏览器扩展列表中且已启用。在用户同意并提供的普通非敏感网页上演示一次翻译。没有实际完成的生词保存、闪卡同步或安装，不得报告为成功。告诉用户扩展装在哪个浏览器、如何从工具栏打开、在哪里卸载，以及哪些步骤尚未完成；未经允许不上传、保存或分享用户的网页内容。
