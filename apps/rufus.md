# Rufus（制作系统启动 U 盘）

上游项目：https://github.com/pbatard/rufus ；官网：https://rufus.ie/zh/ ；常见问题：https://github.com/pbatard/rufus/wiki/FAQ 。

## 安装前

Rufus 只能在 Windows 8 或更新的系统上运行。先问清楚用户的电脑是 x64、x86 还是 ARM64（不确定就在“设置 → 系统 → 系统信息”里看“系统类型”），再选版本：

- 大多数电脑：`rufus-<版本>.exe`（标准版，x64）
- 不想在电脑上留配置：`rufus-<版本>p.exe`（便携版，x64）
- 32 位系统：`rufus-<版本>_x86.exe`
- ARM 电脑（如骁龙笔记本）：`rufus-<版本>_arm64.exe`

告诉用户：Rufus 写 U 盘时会**清空整个 U 盘**，开始前要先把里面的文件备份好。

## 安装

1. 只从官方渠道下载：GitHub Releases（https://github.com/pbatard/rufus/releases/latest ）或官网下载表。不要用第三方下载站。
2. 下载到用户指定的文件夹（默认“下载”）。在文件属性的“数字签名”里核对签名者是 `Akeo Consulting`，对不上就删掉并告诉用户。
3. Rufus 不用安装，双击 exe 就能打开。第一次运行，Windows 会弹出管理员权限确认（Rufus 需要它来写 U 盘），这一步请用户本人点“是”。打开时问是否联网检查更新，可以按用户意愿选择。

## 使用提醒

- 选“设备”时，必须和用户一起确认是哪个 U 盘（看盘符和容量）。没有用户明确同意，不点“开始”，也不格式化任何磁盘。
- 需要 Windows 镜像时，可以用“选择”旁边的下拉箭头切换到“下载”，从微软官方下载 Windows 10/11 镜像；也可以用用户自己已有的 ISO。
- 用 Windows 11 镜像做 U 盘、点“开始”后，会弹出“Windows 用户体验”对话框，可以勾选去掉 TPM/安全启动/4GB 内存要求、去掉在线微软账户要求、跳过隐私问题、建立本地账户。每一项都让用户自己决定。去掉要求只是打开微软安装程序自带的开关，不能让太老的处理器支持 24H2 以后的 Windows 11。
- 怀疑 U 盘是扩容盘时，可以在“显示高级格式化选项”里勾选“检查设备坏块”，Rufus 会顺带检测虚标容量。这个检查同样会清空 U 盘，并且比较耗时。
- 不帮用户激活或破解 Windows，也不下载非官方的系统镜像。

## 验收与交付

确认 exe 已下载、签名是 `Akeo Consulting`、能正常打开到主界面。告诉用户文件放在哪个文件夹、下的是哪个版本、以后怎么打开，以及哪些步骤（选 U 盘、点开始）还需要他自己确认。没有实际做好的启动 U 盘，不要报告为已制作成功。
