# RustDesk

- 项目主页：https://github.com/rustdesk/rustdesk（AGPL-3.0 许可）
- 作用：免费远程控制 帮爸妈修电脑。开箱即用 · ID+密码就能连；全平台互相控制；可自建服务器。
- 支持系统：Windows / macOS（部分还有 Linux、手机版）

## 下载渠道（按优先级）

1. 官网：https://rustdesk.com
2. GitHub Releases：https://github.com/rustdesk/rustdesk/releases/latest

按系统选择文件（文件名会随版本变化，以 Releases 页面为准）：

| 系统 | 参考文件名 |
|---|---|
| Windows | rustdesk-1.5.0-aarch64.exe、rustdesk-1.5.0-aarch64.msi、rustdesk-1.5.0-x86-sciter.exe |
| Mac 苹果芯片 | rustdesk-1.5.0-aarch64.dmg |
| Mac Intel | rustdesk-1.5.0-x86_64.dmg |

## 安装步骤

- Windows：运行安装包按提示安装；免安装版解压后直接打开。
- macOS：打开 `.dmg`，把应用拖进「应用程序」。

## 验证方法

- RustDesk 能正常打开主界面。

## 常见问题

- **Windows 提示“Windows 已保护你的电脑”：** 确认文件来自上面的官方渠道后，点「更多信息 → 仍要运行」。执行前先告诉用户原因。
- **macOS 提示无法验证开发者：** 到「系统设置 → 隐私与安全性」点击「仍要打开」。执行前先告诉用户原因。
- 请只在获得对方授权的设备上使用远程控制。
