# Text-Grab

- 项目主页：https://github.com/TheJoeFin/Text-Grab（MIT 许可）
- 作用：Windows屏幕文字提取神器。按快捷键框选，毫秒级提取不可复制的文字并复制到剪贴板；支持表格抓取、全屏识字、完全本地离线。
- 支持系统：仅 Windows 10 / 11
- **注意：** 这款软件仅支持 Windows。用户是 macOS 或 Linux 时，如实说明，不要尝试安装。

## 下载渠道（按优先级）

1. 微软商店：https://apps.microsoft.com/detail/9msxbzhnf0jl
2. GitHub Releases：https://github.com/TheJoeFin/Text-Grab/releases/latest

## 安装步骤

- 微软商店：打开商店页面，点击获取或安装。
- GitHub Releases：下载 `Text-Grab.exe` 或便携包，解压后双击运行。

## 验证方法

- 运行 Text-Grab，按下快捷键（默认 Win + Shift + F），屏幕出现选区框，框选一段文字后松开，能自动识别并将文字复制到剪贴板。

## 常见问题

- **Windows 提示“Windows 已保护你的电脑”：** 确认文件来自官方 Releases 后，点击「更多信息 → 仍要运行」。执行前先告诉用户原因。
- 本地 OCR 依赖系统自带语言包，如需识别特定语言，可在 Windows 设置中安装对应的语言支持。
