# TranslucentTB

- 项目主页：https://github.com/TranslucentTB/TranslucentTB（GPL-3.0 许可）
- 作用：任务栏一键变透明。透明 · 模糊 · 亚克力；按场景自动切换；只占几 MB 内存。
- 支持系统：仅 Windows（个别也支持 Linux）
- **注意：** 这款软件不支持 macOS。用户是 Mac 时，如实说明并推荐清单里支持 Mac 的软件，不要尝试安装。

## 下载渠道（按优先级）

1. 官网：https://translucenttb.github.io
2. 微软商店：搜索「TranslucentTB」（Windows 用户优先）
3. GitHub Releases：https://github.com/TranslucentTB/TranslucentTB/releases/latest

按系统选择文件（文件名会随版本变化，以 Releases 页面为准）：

| 系统 | 参考文件名 |
|---|---|
| Windows | bundle.msixbundle |

## 安装步骤

- Windows：运行安装包按提示安装；免安装版解压后直接打开。
- macOS：打开 `.dmg`，把应用拖进「应用程序」。

## 验证方法

- TranslucentTB 能正常打开主界面。

## 常见问题

- **Windows 提示“Windows 已保护你的电脑”：** 确认文件来自上面的官方渠道后，点「更多信息 → 仍要运行」。执行前先告诉用户原因。
- **macOS 提示无法验证开发者：** 到「系统设置 → 隐私与安全性」点击「仍要打开」。执行前先告诉用户原因。
