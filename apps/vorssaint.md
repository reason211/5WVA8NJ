# Vorssaint：Mac 菜单栏工具箱

- 项目主页：https://github.com/vorssaint/vorssaint-utils（GPL-3.0 许可）
- 作用：一个菜单栏图标里集成了单独调节每个 App 的音量、剪贴板历史、窗口分屏、系统监控、卸载器等十几个小工具，按需安装功能，无账号、无订阅。
- 支持系统：**仅 macOS 14 及以上，且只支持 Apple 芯片（M 系列）。** Windows 和 Intel Mac 请改装清单里的其他软件。

## 下载渠道

1. 官网：https://vorssaint.com
2. GitHub Releases：https://github.com/vorssaint/vorssaint-utils/releases/latest （文件名 `Vorssaint-版本号.dmg`）

## 安装步骤

1. 打开 `.dmg`，把 Vorssaint 拖进「应用程序」。
2. 首次打开时它会让用户挑选要启用的功能，并只申请这些功能需要的权限（如辅助功能）。**由用户自己勾选功能和授权**，AI 不要替用户开启系统权限。

## 验证方法

- 菜单栏出现 Vorssaint 图标，点开能看到功能面板。

## 常见问题

- **提示无法验证开发者：** 到「系统设置 → 隐私与安全性」点击「仍要打开」。执行前先告诉用户原因。
