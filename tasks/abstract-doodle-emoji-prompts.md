# 抽象涂鸦表情词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

想要表达的日常情绪（如摸鱼/震惊/躺平）和底色偏好。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问需要的情绪状态和背景色偏好，确认只做原创简笔小涂鸦，不模仿现有动漫或影视吉祥物。
2. 按打工人日常、社交装傻、吃喝开心和突然震惊4组生成12套提示词，写清歪扭线条和夸张比例。
3. 每套给出1条完整生图指令和纯色留白建议，排除复杂背景和多余装饰。
4. 说明出图后如何裁剪或加白字做成聊天表情，并核对12套提示词都包含情绪和线条描述。

## 产出

abstract-doodle-emoji-prompts.md：12套涂鸦表情提示词、构图比例和配色建议。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

包含4组共12套原创涂鸦表情提示词，每套含线条特征和纯色留白说明。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
