# 主动阅读提问

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

阅读目标和有权使用的摘录或笔记。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认阅读目标、原创笔记和资料边界；只用用户有权使用的摘录，隐私信息用代号。
2. 按概念理解、证据追问、观点比较、实际应用4组各写3套，共12套可复制提问模板，每套含摘录、问题和回答依据变量。
3. 提供一段原创短文与填写示例；排除整本复制、虚构原文观点或未提供来源的引用。
4. 说明逐条提问和回查原文的方法，自查是否区分原文观点与个人推论，资料不足处标待查。

## 产出

active-reading-prompts.md：12套阅读提问、原创示例和使用说明。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套提问分4组，均含可替换变量，附原创示例、排除要求与回查说明。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
