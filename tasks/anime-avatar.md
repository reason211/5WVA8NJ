# 原创二次元头像

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

原创角色设定和配色。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问角色年龄段、发型、服装、性格和用途，只使用原创或用户有权使用的设定。
2. 设计校园日常、轻幻想、未来都市、自然旅行4组，各3条不同情绪和构图；不使用现有动漫角色名或画师名。
3. 每条写清半身近景、1:1裁切安全区、主色、光线、背景和排除要求；避免未成年色情化内容。
4. 附角色一致性变量表和修改示例，只生成文本，不调用图像模型。

## 产出

anime-avatar.md：12条角色头像提示词及角色变量表。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12条完整提示词，分4组，每条包含构图与配色；原创、非色情，不承诺角色跨图绝对一致。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
