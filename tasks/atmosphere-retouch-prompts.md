# 氛围感修图词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

照片原有场景和你想调整出的光线氛围。缺少影响结果的信息先问用户。

## 执行步骤

1. 先让买家描述手头照片的场景光线和想改的方向，确认只处理买家自己有权编辑的照片，不含他人隐私。
2. 按午后暖阳逆光、复古胶片颗粒、阴天清透冷调、夜市霓虹人像4组，写出12套修图指令模板。
3. 每套给一个日常街头或咖啡馆拍照的原创改写示例，明确写清保留人脸特征、不乱改背景物体。
4. 附上常见修图翻车排查表，教买家在画面过曝或肤色发灰时怎么微调光影词。

## 产出

atmosphere-retouch-prompts.md：12套修图提示词、原创示例和替换参数说明。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套修图提示词分4组写全，每套都有原创示例和保留原图细节的说明。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
