# 考勤记录模板

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

月份、脱敏名单和自定考勤规则。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问年份月份、人员代号、周工作安排、节假日来源和状态代码；法定节假日未经核实不得自动推断。
2. 生成该月全部有效日期和星期，按用户确认的工作安排标记计划工作日；姓名可使用代号。
3. 为出勤、请假、缺勤、休息等用户确认状态设置填写说明与计数公式，不进行薪酬扣减或法律判断。
4. 仅在独立演示副本放虚构示例，正式模板保持待填；提供3条示例与手工计数对照验证公式。
5. 检查月天数、闰年、跨月日期和状态汇总，公式不能可靠生成时明确停下或经同意交付无公式版本。

## 产出

attendance.xlsx：考勤记录、状态说明及汇总页。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

日期与月份完全对应，正式模板无伪造考勤；演示数据标为虚构，计数复核通过。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
