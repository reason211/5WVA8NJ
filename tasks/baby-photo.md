# 宝宝百天照提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

宝宝照片和喜欢的风格。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问宝宝月龄、照片情况和喜欢的风格；只使用用户自家宝宝的照片，提醒不要外传隐私信息。
2. 按国风、童话、森系、节日、职业扮演5组各写4条提示词，每条含场景、服装、道具、光线和构图，保持宝宝面部特征不变。
3. 每条附排除要求（不改五官、不加文字水印、不夸张变形）和推荐画面比例。
4. 说明参考照片要求（正脸清晰、光线均匀）与在可用生图工具中的使用步骤，提示生图可能另耗积分。

## 产出

baby-photo.md：20条风格提示词、照片要求和使用步骤。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。
