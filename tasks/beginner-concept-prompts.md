# 概念入门提问词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

目前卡住的专业名词或课程章节名称。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认想学的学科方向和当前看不懂的名词，说明所有解释仅作入门辅助，不替代教材原文。
2. 按生活类比、拆解前置知识、正反例子对比和3题随堂小测4组生成12套提问指令。
3. 挑1个常见概念做完整示范，展示从听不懂到做对自测题的追问过程，排除堆砌术语的回答方式。
4. 说明如何把自己的课本段落粘进指令里反复追问，并检查12套指令和示范过程都已写清。

## 产出

beginner-concept-prompts.md：12套概念拆解提问指令、类比示范和自测题模板。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

输出4组共12套零基础提问指令，并附1份完整概念拆解与自测示范。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
