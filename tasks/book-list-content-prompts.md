# 书单图文提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

书名或主题方向、自己记下的几条笔记。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认书单主题和买家自己整理的读书笔记，明确只基于合法公开书目与个人笔记提炼，不复制全书内容。
2. 按主题合集、单本金句、反常识观点、适用人群推荐4组生成12套提示词，规定每张图卡的字数上限。
3. 每套给出一条卡片文字排版示范和常见误区，避开长篇大论堆字和生硬的鸡汤总结。
4. 附上排版字数自查表和配图风格建议，买家把自己的笔记塞进去就能出整套图文稿。

## 产出

book-list-content-prompts.md：12套书单拆解指令、卡片文字模板和引用规范。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套书单拆解指令限制单卡字数，附排版示范。
