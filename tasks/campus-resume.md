# 校招简历先整理

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

教育背景、真实项目和目标岗位。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问目标岗位、教育背景、课程项目、社团活动和已有技能；没有的经历留空，不代填。
2. 从真实素材中选与岗位相关的内容，明确标注课程、个人或社团项目，禁止写成商业任职。
3. 按教育、技能、项目、活动生成一页优先的文本，项目用目标、个人行动、真实结果组织。
4. 列出可补充的作品链接、职责细节和待核实技能，附岗位匹配表，不自动投递。

## 产出

campus-resume.md：一版简历文本、素材追问与岗位匹配表。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

一版可编辑文本，项目性质标注清楚；无虚构公司、证书、奖项或任职。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
