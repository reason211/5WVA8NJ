# Q版头像提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

喜欢的配色和人物特点。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问形象特点、配色、用途；无照片也能用文字设计原创角色。
2. 按简笔画、黏土、纸雕、像素4类各做3条；每条包含主体、表情、构图、光线、背景、1:1比例。
3. 为每条补充不要多手指、文字水印、背景杂乱等排除要求；列出可替换的发型、衣着、配色变量。
4. 仅输出文字，不调用生图服务；附把一条提示词粘到买家可用生图技能中的方法，并提示生图另耗积分。

## 产出

cartoon-avatar.md：12条完整中文提示词、变量表及使用说明。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

共12条，4类各3条，每条独立可复制，包含1:1构图；不含真人冒用或版权角色。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
