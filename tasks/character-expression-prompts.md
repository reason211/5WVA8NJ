# 角色表情生图

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

原创角色外貌、服装和画面风格。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认原创角色外貌、服装和画面风格；确认内容为原创，只使用用户有权使用的资料，涉及隐私时用代号。
2. 按开心、惊讶、困惑、平静4组各写3套，共12套可复制的提示词，写明原创角色外貌、服装、情绪和视角等填写项。
3. 给出一个关于原创邮差角色收到信时的惊讶表情的原创填写示例；不要使用现有影视游戏小说角色、真人仿冒和在世作者文风。
4. 说明如何填写和调整提示词，检查内容是否符合输入信息，并列出使用前要核对的事项。

## 产出

character-expression-prompts.md：12套提示词、原创示例和使用检查清单。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套提示词分成4组，包含填写项、原创示例、排除要求和使用前检查清单。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
