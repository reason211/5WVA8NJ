# 人物设定提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

题材、角色定位和性格关键词。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问题材、角色定位（主角、反派、配角）、性格关键词和故事背景；只生成原创角色。
2. 按古风、修仙、现代都市、校园、悬疑5类各写一条人物设定提示词，要求输出外貌、出身、动机、秘密、性格反差和口头禅。
3. 提供统一角色卡模板和一个原创填写示例。
4. 附人物关系图指令：输入多张角色卡，输出人物关系、冲突点和可展开的剧情。

## 产出

character-sheet.md：5类题材人物设定提示词、角色卡模板与关系图指令。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

5类提示词、角色卡模板、原创示例和关系图指令齐全。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
