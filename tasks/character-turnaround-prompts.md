# 角色三视图词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

角色性别、职业气质和2个外观特征。缺少影响结果的信息先问用户。

## 执行步骤

1. 先确认角色体型、时代背景和两个好认的配饰，明确要求原创设定，不用已有影视游戏角色。
2. 按现代日常、校园制服、东方古风、轻科幻4组，写出12套正侧背三视图生图提示词。
3. 每套列出固定发色、服装款式和鞋袜细节的锚点词，排除透视错位、缺胳膊和换衣服的问题。
4. 附上后续做分镜时保持人物长相不变的用法说明，和一份三视图自查清单。

## 产出

character-turnaround-prompts.md：12套三视图提示词、配色卡和锚点词。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套三视图提示词覆盖4种题材，每套都有正侧背指令、锚点词和排除要求。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
