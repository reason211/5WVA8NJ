# 电影感街拍

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

人物性别穿搭、拍摄时间段和想要的情绪氛围。缺少影响结果的信息先问用户。

## 执行步骤

1. 先确认人物造型、所在街道环境和色调偏好，只使用虚拟人物描述或买家自己有权处理的照片。
2. 按夜景霓虹、雨后积水、黄昏逆光和胶片抓拍4组，写出12套电影感街拍提示词，写清焦段和光位。
3. 每套配一组完整提示词示例，标出容易让皮肤偏色或背景糊成一团的禁用词。
4. 附上镜头焦段、胶片颗粒和色温调整说明，方便按不同生图工具微调。

## 产出

cinematic-street-portrait-prompts.md：12套光影人像词、镜头焦段表和原创示例。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。
