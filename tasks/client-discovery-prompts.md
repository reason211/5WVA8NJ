# 客户需求梳理词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

脱敏后的客户聊天记录或简要业务背景。缺少影响结果的信息先问用户。

## 执行步骤

1. 请用户贴入脱敏后的沟通记录或业务描述，确认涉密客户名称、联系方式和底价均已用代号替换。
2. 按初次接洽、范围边界、预算工期和验收标准4组生成12套需求提问提示词，帮AI快速找出模糊点。
3. 用其中最贴合的2套指令处理用户提供的资料，生成一份待确认问题列表，并排除空泛客套话。
4. 说明发给客户前的人工核对要点，确认12套指令齐全且产出的确认单能直接对照修改。

## 产出

client-discovery-prompts.md：12套需求梳理提示词和一份脱敏需求确认单初稿。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

包含4组共12套需求梳理指令，并附一份基于用户脱敏资料的确认问题清单。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
