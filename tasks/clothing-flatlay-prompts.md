# 服装平铺生图

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

自有服装信息、配色和展示用途。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认服装特点、展示用途和原创风格；只用用户有权使用的资料，隐私信息用代号。
2. 按纯色背景、自然桌面、几何陈列、柔光布景4组各写3套，共12套独立提示词，包含服装特征、背景、光线和画幅变量。
3. 附一套虚构服装填写示例；排除人物、未经授权标志和夸张变形，不新增无依据的商品功能或细节。
4. 说明如何在可用生图工具中替换变量并对照实物核验款式与颜色；只交付文本，生图可能另耗积分。

## 产出

clothing-flatlay-prompts.md：12套生图提示词、变量示例和核对说明。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套提示词分4组，均含构图变量与排除要求，并附示例和实物核对说明。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
