# 漫剧站位运镜词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

人物数量、场景大小和一段简短的动作剧情。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认人物数量、画面比例和原创要求，不用任何已有IP角色或真实明星外貌。
2. 按双人对峙、转身回眸、奔跑追逐和室内互动4组生成12套提示词，标明人物左右站位、视线和镜头推拉。
3. 每套附1段改写前后的对比示例，并列出容易导致肢体错位的词，提醒在生成时排除。
4. 给出套用自己剧情的步骤，并自查12套提示词是否都写清了人物位置和镜头方向。

## 产出

comic-action-blocking-prompts.md：12套角色站位与运镜提示词、动作描述模板。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

4组共12套提示词均标明人物站位、动作走向与镜头运动，无现有IP。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
