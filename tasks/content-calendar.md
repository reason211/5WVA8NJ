# 14天选题日历

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

账号方向、受众和可用素材。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问领域、受众、平台、开始日期、每天可投入时长、已有素材和商业合作情况。
2. 按教程、问答、复盘、清单等内容类型分配14天，依据生产能力控制工作量。
3. 每行输出日期、主题、受众问题、内容结构、素材清单、预计准备时间、事实核验项，写UTF-8带BOM的CSV。
4. 提出收藏、评论质量等观察指标，明确无历史基线时只能试验，不凭空预测涨粉或收益；不执行定时发布。

## 产出

content-calendar.csv与说明.md：14天选题表、内容比例和复盘指标。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

14个连续有效日期、14个非重复选题，每天有素材和准备动作，CSV能正常读取。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
