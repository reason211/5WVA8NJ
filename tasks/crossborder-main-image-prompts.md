# 跨境主图提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

商品品类、尺寸特点和目标使用场景。缺少影响结果的信息先问用户。

## 执行步骤

1. 先让买家说明商品种类、材质颜色和常见使用环境，确认只用于自有商品展示，不带他人品牌标志。
2. 按欧式客厅桌面、自然户外阳光、厨房实用操作台、极简工作室4组，写出12套场景主图生图提示词。
3. 每套给一个常见家居小物或数码配件的原创中英提示词示例，要求光线自然、背景不抢商品主体。
4. 附上生图后的细节核对清单，提醒买家检查产品比例、材质反光和画面里有没有多余文字。

## 产出

crossborder-main-image-prompts.md：12套生图提示词、中英对照示例和出图检查项。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套场景生图提示词分4组写全，每套都带原创中英示例和主体保留约束。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
