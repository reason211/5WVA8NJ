# 日用百货主图词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

商品品类、材质特点和主要使用房间。缺少影响结果的信息先问用户。

## 执行步骤

1. 先确认商品名称、材质和使用场景，提醒只用自有商品信息，不用他人店铺原图直接洗稿。
2. 按纯色白底、桌面陈列、居家实景、局部细节4组，写出12套电商主图提示词和留白位置。
3. 每套给一个原创日用品示例，附上排除杂物、畸变文字和多余商标的负面词。
4. 写出常见比例设置和自查要点，帮买家核对主体是否居中、卖点区域是否空出。

## 产出

daily-goods-main-image-prompts.md：12套主图提示词、构图比例和排除词。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套主图提示词分4组完成，每套包含场景词、留白位置和负面排除词。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
