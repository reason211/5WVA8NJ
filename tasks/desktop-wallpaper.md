# 桌面壁纸提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

显示器比例、主题和图标位置。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问显示器比例、分辨率、图标排列位置；默认16:9，超宽屏按用户提供的比例写。
2. 设计自然远景、抽象几何、空间光影、低饱和色块4组各3条。
3. 每条写明横向构图、图标侧低细节留白、主体位置、色调、光线与排除文字水印的要求。
4. 附亮暗两种修改方式和实际桌面预览检查项；仅输出文字包。

## 产出

desktop-wallpaper.md：12条横屏提示词及比例调整说明。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12条完整横屏提示词，均标注比例和图标安全区；不虚称图片分辨率已生成。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
