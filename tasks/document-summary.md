# 长文档先抓重点

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

有权使用的文档和阅读关注点。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认阅读目的、文件权限和资料范围，统计可读页码或章节；扫描件需要OCR时另行说明并取得同意。
2. 分章节抽取主题、数据、结论与限制，每项保留PDF物理页码或章节标题及段落编号。
3. 归纳约600至900中文字的一页阅读稿，区分原文结论与AI归纳，保留不确定性与反例。
4. 附5个可继续核实的问题及出处表，不能访问的页或解析失败内容列入未读范围。
5. 逐项检查关键数字和原文位置，不用未读取的附件补全论证，不提供法律、医疗等专业结论。

## 产出

document-summary.md：约600至900字摘要、出处表和待核实问题。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

摘要、出处表、5个问题齐全，每个关键结论有可定位来源，未读范围明示。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
