# 英文简历对照改

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

脱敏中文简历和目标英文岗位。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认英式或美式英语、岗位要求和脱敏简历，保留原始事实与时间。
2. 将职责改写为简洁英文行动句，保持原技能熟练度，不添加夸大的领导、流利、精通表述。
3. 生成英文简历与逐段中英对照；学校、公司、证书正式译名无依据时标待核实。
4. 核对数字、年月、姓名拼写和时态，列出有歧义的表达供用户确认。

## 产出

english-resume.md：英文简历、中英逐段对照和专名待核实表。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

英文完整稿、逐段对照与术语核对表齐全，数字日期与中文原稿一致。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
