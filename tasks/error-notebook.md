# 错题变复习卡

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

已完成练习、你的作答和参考答案。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认是已完成的日常练习，不是正在进行的考试；只处理用户有权提供的题目、作答与答案。
2. 为题目编号，保留用户原作答，比较参考答案；没有可靠答案时标未核实，不把推断写成官方解析。
3. 将错因分为概念、计算、审题、步骤遗漏等，以原作答为依据；无足够证据时提出追问。
4. 每题生成知识点、正确思路、易错提醒和一个自查问题，卡片正反面分别写提问与复习要点。
5. 核对题目与卡片编号一一对应，标出需老师或权威资料核实的解题步骤，不承诺提分。

## 产出

error-notebook.md与review-cards.csv：错题索引、错因与复习卡。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

所有输入错题均有索引与对应卡片，原作答未丢失，答案可靠性和推断部分标注清楚。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
