# 活动执行出清单

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

活动主题、参与人数、时间和预算上限（单位和人名用代号）。缺少影响结果的信息先问用户。

## 执行步骤

1. 请买家给出活动主题、大概人数、场地类型和预算上限，如涉及公司名称或具体同事请用代号代替，只依据提供条件规划，不乱加超出预算的项目。
2. 按前期筹备倒排表、当天流程时间轴、岗位分工占位、物料与预算估算4个板块输出本次活动执行方案。
3. 另外整理1套通用的活动策划提示词模板，明确排除空喊创意口号、没有负责岗位的任务和漏算备用耗材的写法。
4. 说明下次办沙龙或团建时怎么改参数直接复用模板，并附一条核对场地电源、应急雨备和预算总和的自查项。

## 产出

event-planning-prompts.md：本次活动执行流程、分工表、物料预算表与通用策划指令。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

产出包含4板块的本次活动方案与预算清单，并附1套可复用策划指令。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
