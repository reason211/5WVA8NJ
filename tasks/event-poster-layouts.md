# 活动海报构图

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

活动主题、画幅和希望的配色。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认活动主题、画幅、原创风格与资料边界；只用用户有权使用的资料，隐私信息用代号。
2. 按极简几何、植物插画、纸艺层次、抽象光影4组各写3套，共12套提示词，包含主体、配色、标题留白和画幅变量。
3. 附一个虚构活动的填写示例；排除现有作品元素、未经授权标志、真人仿冒和自动生成的小字。
4. 说明提示词使用与后期添加文字的方法，自查日期地点及阅读对比度；只交付文本，生图可能另耗积分。

## 产出

event-poster-layouts.md：12套生图提示词、版式示例和文字核对说明。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套提示词分4组，均含画幅与留白，附示例、排除要求及文字核对说明。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
