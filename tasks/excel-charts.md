# 明细变汇总图表

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

脱敏明细表、指标和统计口径。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认日期字段、分组字段、指标、单位、统计期间、重复与空值规则；预览样本并请求口径确认。
2. 先生成按时间趋势、类别对比、构成分析3份汇总表；非可加指标如比率、均价按分子分母重新计算，不直接求和或平均。
3. 按数据性质生成3张图：折线、条形、构成条形或适合的替代图；缺少时间或类别字段先询问，不捏造字段。
4. 写清图表标题、单位、轴标签、数据期间和空值处理，输出新工作簿、PNG图及一页描述性说明。
5. 复算汇总值与原始明细、抽查2组数据，区分事实观察和解释假设，不能从相关性推断因果。

## 产出

summary.xlsx、3张PNG图和summary.md。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

3张图与汇总表口径一致，抽查复算通过，缺失和异常已说明，无虚构因果结论。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
