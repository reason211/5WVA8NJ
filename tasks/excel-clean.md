# 表格清洗有记录

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

脱敏Excel副本和去重字段。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问工作表、表头行、去重键、首末记录保留规则和空值处理；先预览5行与行数，用户确认规则再处理。
2. 身份证号、电话、订单号按文本保留前导零与长整数；不将不同日期或空键行随意视作重复。
3. 按确认规则清理首尾空格、统一指定格式并去重；原始表不变，输出新文件和逐项变更记录，空值不擅自补成0。
4. 若有公式、宏、透视表或外部连接，先说明保真限制；不能可靠保留时停下或经同意输出仅含值的副本，不执行宏。
5. 核对输入行数=保留行数+移除行数，抽查原始/清洗结果，报告未处理项。

## 产出

cleaned.xlsx、changes.csv与check.md；缺少XLSX能力时先说明并征得CSV降级同意。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

行数守恒、去重键与保留规则明确，原文件未覆盖，长编号和前导零未丢失。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
