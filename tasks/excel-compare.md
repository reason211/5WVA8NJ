# 两张表哪里不同

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

两份脱敏表、匹配键和比对字段。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认旧表与新表、表头、匹配键、比对字段、大小写与空值规则；金额等数字误差容忍度必须由用户确定。
2. 匹配键按文本读取以保留前导零；检测重复键及空键，单独列出，未确认一对多规则前不强行匹配。
3. 按确认规则生成仅新表存在、仅旧表存在、共同键字段变化三类明细，变化项包含旧值与新值。
4. 输出新工作簿和未匹配原因，原文件不改；数字只对确认字段按确认精度比较，其他保持原值。
5. 核对各类键数量与两张原表的去重键数量对应，抽查至少3条差异或在不足3条时全部抽查。

## 产出

comparison.xlsx：新增、缺失、变化、重复键及核对汇总。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

三类差异与重复/空键清单完整，旧值新值可追溯，未把重复键任意一对一配对。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
