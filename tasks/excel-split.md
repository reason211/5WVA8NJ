# 总表按分类拆开

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

脱敏总表、分类字段和输出方式。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认工作表、分类字段、表头行以及每组独立文件还是同一工作簿多个表；读取5行预览并确认。
2. 将分类值映射为安全文件名或工作表名，去除路径字符，处理空值、31字符限制、大小写和截断重名；保存原值到输出名映射。
3. 逐组输出，保留表头和编号文本；缺失分类写入独立的未分类组，不能静默丢行。
4. 只生成新文件，不自动发给部门成员；遇到公式、宏或格式保真问题先说明并确认处理方式。
5. 复核分组行数之和等于原数据行数，抽查各组分类值与映射表。

## 产出

分组后的新工作簿、group-map.csv与核对报告。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

分组行数守恒，所有输出名唯一且不越界，未分类数据保留，未发送文件。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
