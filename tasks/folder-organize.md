# 文件分类先试一版

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

指定文件夹和分类方式。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认指定输入目录、是否递归和新输出目录，输出目录必须在输入树外以免递归复制；不跟随符号链接，不扫描全盘。
2. 按扩展名或用户指定时间字段规划分类，未知类型放其他；日期取修改时间还是原始拍摄时间必须由用户确认。
3. 计算待复制文件数和总大小，检查可用空间并给3个样例与冲突处理方案；获得确认再复制，不搬移或删除原件。
4. 保留原名；同名文件按稳定序号生成新名并写映射，大小写不敏感系统也要检查冲突，不覆盖目标。
5. 核对成功复制数量、大小与代表性文件校验值，列出权限不足、链接和失败项目；不把未复制项当成功。

## 产出

整理后的新目录、file-map.csv与跳过/冲突报告。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

原目录未改动，输出目录在输入树外，数量、大小核对及原新路径映射可用。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
