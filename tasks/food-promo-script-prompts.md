# 美食带货脚本词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

食品名称、主要口味特点和目标买家（上班族/家庭等）。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认食品品类、卖点和食用场景，所有描述只基于实物包装和真实口感，不夸大、不写违规功效词。
2. 按开箱特写、夜宵解馋、配料实拍和吃法花样4组生成12套提示词，写清前3秒开口和画面动作。
3. 每套附1段40字左右的原创口播示例，并标出需要避开的绝对化广告词。
4. 说明拍摄前如何核对台词和商品信息，并自查12套脚本提示词是否覆盖4种场景。

## 产出

food-promo-script-prompts.md：12套美食带货口播提示词、镜头提示和合规清单。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收
