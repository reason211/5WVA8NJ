# 手绘插画提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

想画的物体或小场景（如咖啡杯/街角书店）和色调偏好。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认要画的主题、画面用途和色调，规定只用画材和笔触词，不使用任何在世画家或插画师名字。
2. 按水彩湿画、彩铅叠色、蜡笔厚涂和钢笔速写4组生成12套提示词，写明纸张纹理和线条粗细。
3. 每套给出1条完整可直接复制的原创例句，并列出容易让画面变塑料感的词用于排除。
4. 说明怎么替换例句里的主体名词来复用，并自查12套画材、纸纹和负向词是否齐全。

## 产出

hand-drawn-illustration-prompts.md：12套手绘笔触提示词、纸张肌理词和完整例句。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

4组共12套手绘提示词均含画材笔触、纸张肌理与原创例句，无画家姓名。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
