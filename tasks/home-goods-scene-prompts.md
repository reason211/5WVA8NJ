# 家居主图词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

家居产品名称、摆放位置和想突出的实用卖点。缺少影响结果的信息先问用户。

## 执行步骤

1. 先确认产品用途、体积大小和主要摆放房间，只用用户自有产品信息，不带第三方品牌标志。
2. 按书桌收纳、阳光客厅、整洁厨房和浴室角落4组，生成12套家居场景主图提示词，写明机位和道具搭配。
3. 每套补一组构图示例，提醒别在背景堆太多杂物，确保视线留在商品主体上。
4. 附上常用材质反光控制词和使用自查清单，买家拿到就能按自家商品改写。

## 产出

home-goods-scene-prompts.md：12套家居布景词、光影构图示例和避坑提醒。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套家居场景提示词分4组并带示例，含杂物排除提醒和材质词表。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
