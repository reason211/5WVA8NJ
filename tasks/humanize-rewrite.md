# 去AI味改写指令

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

需要润色的自有文字和目标风格。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问文字用途（小说、文案、公文、日记等）、目标读者和希望的语气；只处理用户自己写的文字。
2. 按句式变化、删除套话、抽象改具体、长短句节奏、口语化、情绪层次6组各写5条改写指令，每条说明作用。
3. 每组给一段原创原文与改写后的对照示例。
4. 附推荐使用顺序和自查清单（套话、排比堆砌、空泛形容词），提醒最终由作者通读修改。

## 产出

humanize-rewrite.md：30条改写指令、前后对照示例和自查清单。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

30条指令分6组，每组有原创对照示例，并附自查清单。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
