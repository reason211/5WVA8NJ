# 图片格式批量转

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

图片副本、目标格式和质量要求。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认有权处理的图片目录、是否递归、PNG/JPEG/WebP目标格式、尺寸与质量；GIF动画和多页图默认排除并列出。
2. 使用系统或已安装工具检查实际格式而非只看扩展名；工具缺失时先请求依赖安装许可，不能仅更改后缀。
3. JPEG不支持透明，先询问填充背景色；说明有损压缩不可逆、元数据和ICC色彩配置的保留策略，定位隐私信息处理需用户选择。
4. 在独立目录先转换最多3张样例，检查方向、透明区、颜色与尺寸，确认后批量处理，重名不覆盖。
5. 重新读取输出核对格式、尺寸与可解码性，统计成功失败及跳过原因，不承诺画质无损或恢复原细节。

## 产出

converted-images目录与conversion.csv：源目标、尺寸、格式与失败项。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

实际编码为目标格式，原图未动，透明与方向正确，输出数量与日志吻合，失败项未伪称成功。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
