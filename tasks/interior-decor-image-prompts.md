# 室内软装生图词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

房间类型、大致面积和喜欢的材质颜色。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问要参考的房间功能、面积大小和偏好的色系材质，使用常见家居词汇描述，不用他人未授权的实景照片隐私细节。
2. 按采光客厅、安静卧室、实用书房、小户型餐厨4组生成共12套软装生图提示词，每套写明地面墙面材质、主家具轮廓和自然光方向。
3. 提供2条能直接拿去生图的完整客厅与书房提示词示例，排除家具比例畸形、窗户悬浮和满屋堆满杂物的乱画面。
4. 说明怎么微调木色深浅和灯光色温关键词，并附一条检查桌腿数量、门框对齐和透视别歪的核对方法。

## 产出

interior-decor-image-prompts.md：12套室内软装生图词、2条完整示例和防穿帮提示。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套软装提示词分4组写清材质与光线，并含2条完整生图示例和检查方法。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
