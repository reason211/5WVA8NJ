# 课件结构先做好

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

年级、知识点和授课时长。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认学段、科目、知识点、教学目标及授权参考资料，不整本复制教材。
2. 规划12页：封面、目标、导入、概念两页、例子两页、练习三页、归纳、课后建议。
3. 围绕用户知识点原创3道练习，分别给出解题过程与答案；不确定的知识标记需教师复核。
4. 用当前可用技能生成可编辑PPTX，不能导出则明确提供逐页稿和题目文本。
5. 检查目标、例子、练习一致性，演算答案，核对页数与投影可读性。

## 产出

lesson.pptx、3道练习及答案说明；导出受限时为逐页稿。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12页、有3道原创练习及对应解答，教师需复核的地方明确列出。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
