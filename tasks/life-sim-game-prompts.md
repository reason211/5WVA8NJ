# 模拟文字游戏词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

喜欢的题材方向、主角开局条件和回合节奏。缺少影响结果的信息先问用户。

## 执行步骤

1. 先问买家喜欢哪种日常模拟题材和每回合想要几个选项，角色和店名全部原创，不碰现有影视或游戏IP。
2. 按小店经营、职场升迁、毕业租房、乡村小院4组生成共10套文字模拟指令，每套写清初始数值、每回合固定面板和突发事件触发方式。
3. 给出一套可直接复制开局的原创小店模拟指令和前两回合示范，排除AI替玩家做决定、数值莫名清零和选项太啰嗦的问题。
4. 说明玩到一半怎么提醒AI记住旧数值继续往下演，并附一条核对选项数量和属性增减的检查办法。

## 产出

life-sim-game-prompts.md：10套模拟游戏指令、1段试玩回合示例和防乱码提醒。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

10套模拟指令分4组含属性与事件规则，并附1套原创开局示范和防跑偏办法。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
