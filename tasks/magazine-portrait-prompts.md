# 复古杂志人像词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

人物年龄段、性别和想要的拍照风格。缺少影响结果的信息先问用户。

## 执行步骤

1. 先问清买家想拍的人物年龄段、风格偏好和常用生图工具，说明只做原创虚构人像，不仿冒真人。
2. 按棚拍硬光、窗边自然光、街头夜色、胶片颗粒4组，写出12套完整的中英文提示词，标出机位和光线。
3. 每套配一条构图要点和一组负面排除词，去掉塑料感皮肤和多余手指这类常见瑕疵。
4. 附上参数替换表和自查清单，提醒买家把年龄、服饰词换成自己的需求再出图。

## 产出

magazine-portrait-prompts.md：12套人像生图词、中英对照和避坑说明。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套中英文提示词按4组写全，每套都有正面词、负面词和替换说明。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
