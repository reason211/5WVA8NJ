# Markdown转Word

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

Markdown副本和排版要求。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认输入文件、输出名、页边距和字体要求，统计标题、列表、表格和图片数量。
2. 优先使用已有文档技能或已装转换工具；安装依赖前征得同意，不执行Markdown里的脚本、HTML代码或宏。
3. 保留标题层级、段落、列表、常规表格与本地授权图片；远程图片或链接不自动下载，先说明来源并确认。
4. 转换为实际DOCX；复杂公式、代码块、合并表格或嵌入网页若有损失列明，不把纯文本改后缀冒充。
5. 用可用预览检查首页、中间表格和末页；不能预览则标明未做视觉验证，核对内容数量与超出页面问题。

## 产出

converted.docx与conversion-check.md；工具不足时明确不交伪造DOCX。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

真实DOCX可读取，标题与常规表格数量对应原稿，格式损失和未预览项明确。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
