# 记忆卡制作指令

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

单词表或知识点文本。缺少影响结果的信息先问用户。

## 执行步骤

1. 读取用户提供的单词表或知识点，确认用途、数量和卡片样式；只处理用户有权使用的资料。
2. 生成正面问题、背面答案、例句或记忆提示三栏卡片，不确定的释义标需复核；输出UTF-8带BOM的CSV，单元格为纯文本。
3. 按间隔复习思路生成7天复习安排，标明每天新学与复习的卡片编号。
4. 附导入Anki等卡片软件的步骤说明，核对卡片数量与原资料一致。

## 产出

memory-cards.csv与cards-guide.md：记忆卡、7天复习安排和导入说明。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

卡片数量与资料一致，三栏完整，复习安排覆盖全部卡片，并含导入说明。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
