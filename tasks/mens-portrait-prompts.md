# 男士人像提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

想要的年龄感、穿搭风格和拍摄场景。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认想要的人物年龄段、服装风格和光线情绪，明确只生成虚拟人像，不使用真人姓名或肖像特征。
2. 按户外街拍、室内窗光、极简棚拍、运动抓拍4组写出12套提示词，写明焦段、光位和皮肤质感词。
3. 每套附带一组动作姿态建议和负面词，避开磨皮过头、眼神空洞和背景路人抢镜的问题。
4. 写出年龄、发型和服装词的替换位置与出图自查步骤，买家复制后换几个词就能出图。

## 产出

mens-portrait-prompts.md：12套男士人像生图词、光影镜头参数和替换示范。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套男士人像词覆盖4类拍摄场景，含姿态与负面词。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
