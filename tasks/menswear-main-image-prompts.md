# 男装主图提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

男装品类、主打季节和目标风格。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认男装款式、季节和店铺调性，明确只用虚拟原创模特和买家自有款型信息，不出现真人明星或品牌商标。
2. 按街头通勤、室内极简、户外机能、细节平铺4组生成12套提示词，写清机位、光线和面料描述。
3. 每套给出一条完整生图示例和常见避坑点，排除畸变手指、衣服纹理糊成一片等常见毛病。
4. 附上主体、背景、光线的替换位置说明与出图自查要点，买家用主流生图工具就能直接改着用。

## 产出

menswear-main-image-prompts.md：12套男装主图生图词、面料光影参数和套用示范。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。
