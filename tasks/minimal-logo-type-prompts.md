# 极简标志提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

小店或项目名称、行业方向和偏好的主色调。缺少影响结果的信息先问用户。

## 执行步骤

1. 先让买家提供原创品牌名、主营方向和两三个想突出的意象，确认不模仿任何已有知名商标。
2. 按极简几何图形、圆润手写字体、复古印章徽章、负空间字母结合4组，写出12套生图提示词。
3. 每套给一个虚构茶饮店或手作坊的原创英文提示词示例，要求纯色背景、线条干净、不要多余渐变阴影。
4. 附上出图筛选和重绘建议，提醒买家挑出轮廓清晰的草图后自己用矢量软件修整再使用。

## 产出

minimal-logo-type-prompts.md：12套设计提示词、原创示例和矢量化整理建议。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套标志设计提示词分4组写全，每套都有原创示例和纯色背景约束。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
