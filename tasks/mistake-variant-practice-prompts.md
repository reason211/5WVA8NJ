# 错题变式提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

一道自己做错的原题和当时的错误思路。缺少影响结果的信息先问用户。

## 执行步骤

1. 先让买家输入自己整理的一道错题和当时选错的原因，确认只用自己有权使用的学习题目。
2. 按数字条件微调、题干情景替换、易错陷阱反问、分步引导解答4组，写出12套变式出题提示词。
3. 每套给一个常见初中数学或英语语法的原创示例，要求先只给新题不直接亮答案，方便自己动手做。
4. 附上错题复盘打卡小表和验算提醒，让买家做完变式题后再核对一遍解题步骤。

## 产出

mistake-variant-practice-prompts.md：12套出题提示词、原创示例和验算自查项。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套变式出题提示词分4组写全，每套都有原创示例和先做题后看答案要求。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
