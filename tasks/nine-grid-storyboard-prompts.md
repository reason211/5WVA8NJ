# 九宫格分镜词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

一段几十秒的原创剧情梗概和出场角色特征。缺少影响结果的信息先问用户。

## 执行步骤

1. 先让买家贴出原创的短剧情节和角色基本穿着，确认只处理买家自己的故事，人物名用代号。
2. 按动作追逐戏、双人情绪对话、日常反转喜剧、悬疑进屋探索4组，写出12套九宫格分镜提示词。
3. 每套配一个9格景别与动作拆解的原创示例，明确要求画风统一、角色衣服前后不穿帮、按顺序编号。
4. 附上常见景别缩写表和自查提示，提醒买家核对第1格到第9格的人物朝向和动作连贯性。

## 产出

nine-grid-storyboard-prompts.md：12套分镜提示词、原创示例和景别对照表。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套九宫格分镜提示词分4组写全，每套都有原创示例和角色一致性约束。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
