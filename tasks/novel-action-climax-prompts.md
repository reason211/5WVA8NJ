# 小说打斗词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

故事背景、双方人物特点和这场冲突想达成的结局。缺少影响结果的信息先问用户。

## 执行步骤

1. 先问清楚小说题材、人物能力设定和这场冲突要推进什么剧情，只用原创设定，不照搬现有作品桥段。
2. 按近身交手、多人混战、反转反杀和情绪爆发4组，生成12套动作与高潮描写提示词，每套写明景别和节奏变化。
3. 每套补一段原创对比示例，标出需要删掉的拖沓废话，提醒别写成流水账式报招名。
4. 附一段套用说明和自查表，教买家把自己的角色名和环境细节填进指令里直接生成初稿。

## 产出

novel-action-climax-prompts.md：12套动作高潮提示词、原创片段示例和节奏检查表。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套打斗高潮提示词分成4组且各有原创示例，并含套用说明和自查表。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
