# 网文开篇指令

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

想写的题材、主角设定和目标平台。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问题材偏好、主角设定、目标字数与平台风格；只使用用户原创设定，不仿写正在连载的作品或作者文风。
2. 按玄幻、都市、言情、悬疑、历史、科幻、末世、校园、种田、仙侠、无限流、职场整理12类，每类写一条开篇指令：主角处境、核心冲突、金手指或悬念、第一章钩子。
3. 每类附人设卡模板（姓名、动机、缺点、成长线）和前三章提纲指令，可替换变量用【】标出。
4. 附使用顺序：先定人设、再生成提纲、逐章扩写、人工修改，并说明AI草稿需作者自行改写润色。

## 产出

novel-opening.md：12类题材开篇指令、人设卡模板与前三章提纲指令。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12类开篇指令齐全，每类含人设卡与前三章提纲指令，变量可替换，不含对现有作品的仿写。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
