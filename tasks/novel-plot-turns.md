# 小说中段推进

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

原创故事梗概、人物目标和已有线索。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认题材、原创故事梗概和写作边界；只用用户有权使用的资料，隐私信息用代号。
2. 按目标受阻、关系转折、线索回收、选择代价4组各写4条，共16条独立可复制的提示词；每条含人物目标、已有线索和限制变量。
3. 提供一组原创梗概与提示词填写示例；排除现有作品人物和情节，不模仿在世作者文风。
4. 说明替换变量和分批使用的方法，自查前后因果与设定一致；缺失设定标待填，由作者审阅。

## 产出

novel-plot-turns.md：16条中段推进提示词、原创示例和使用说明。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

16条提示词分4组，均有可替换变量，附原创示例、排除要求与使用自查。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
