# 小说场景描写词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

小说类型（古代/现代/科幻等）和想要描写的场景气氛。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认小说题材、气氛需要和只写原创内容的边界，人名地名用代号或虚构词，不照搬现有作品。
2. 按自然天气、室内压迫、热闹市井和荒野追逐4组生成12套场景描写提示词，写清光线、声音和气味要素。
3. 每套配1段原创短句示例，并标出最容易写空洞的形容词，提醒改用具体动作和物件替代。
4. 说明如何把当前章节片段喂给AI做扩写，并核对12套提示词、示例和禁用词检查都齐全。

## 产出

novel-scene-description-prompts.md：12套场景描写提示词、光影气味细节和原创片段示例。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

包含4组共12套原创场景提示词，每套都有细节要素和原创句例。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
