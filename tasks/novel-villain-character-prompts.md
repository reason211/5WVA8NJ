# 反派人设词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

主角类型、故事题材和你需要补充的反派或配角位置。缺少影响结果的信息先问用户。

## 执行步骤

1. 先确认故事题材、主角性格和当前缺的角色位置，所有设定全部原创，不模仿现有小说或真人。
2. 按压迫感反派、伪装型对手、关键盟友和烟火气配角4组，写出12套立体人设提示词，带出动机与软肋。
3. 每套配一个原创人物小传示例，并注明要避开的脸谱化毛病，比如无缘无故使坏。
4. 附上人设卡填法说明和检查清单，方便买家照着模板补全自己故事里的配角。

## 产出

novel-villain-character-prompts.md：12套人设提示词、人物小传示例和避雷说明。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套人设提示词分组清楚且各有原创小传示例，含填法说明与检查清单。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
