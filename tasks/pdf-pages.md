# PDF合并或拆分

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

有权使用的PDF和合并顺序或页码。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认用户选择合并或拆分，列出输入顺序、PDF物理页数与页码范围，页码使用从1开始的物理页序，不混用印刷页码。
2. 检查加密、权限和数字签名；受保护文件请用户合法解锁，不破解；重组会影响数字签名时先提示并要求确认。
3. 验证范围为有效页且顺序明确，重复页或跳页若是用户指定则保留并标注，不能擅自补页。
4. 优先使用已有PDF工具，在新目录生成文件，重名不覆盖；无法保留书签、表单或附件时先说明并确认降级。
5. 核对输出总页数与映射一致，并抽看首末及每个合并边界页，若无法视觉预览则如实标注未验证。

## 产出

新PDF文件、页码映射清单与核对报告。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

页数、顺序和原文件映射一致，原件保留，加密或签名限制未被绕过，预览范围已报告。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
