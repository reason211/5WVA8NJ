# PDF表格转可编辑

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

有权使用的PDF及表格页码。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认文件权限和PDF实际物理页码，先识别是文字型还是扫描型；加密文件请用户合法解锁，不破解。
2. 文字型优先读取文本表格；扫描型先检查已有OCR能力，说明准确率、数据流和积分，获得同意再识别，能力缺失就停下说明。
3. 按页提取表头和记录，跨页重复表头不算数据；合并单元格、负号、小数点与长编号重点标记，不猜造看不清的值。
4. 每行或每表附源文件和物理页码，无法确认的单元格留原识别值并标疑似，不静默纠正。
5. 核对表格行列数量，人工式抽查首页、中间、末页或全部不足3页的表格，报告可读范围与未识别部分。

## 产出

pdf-tables.xlsx或经同意的CSV、来源页码及识别问题清单。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

指定表格有来源页码，疑似错误与缺失可见，未将未经核对的OCR声称完全准确。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
