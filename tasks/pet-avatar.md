# 萌宠头像自己做

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

宠物种类、毛色和性格。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问宠物种类、显著毛色、表情和用途；如有参考照片，确认用户拥有使用权。
2. 按毛毡玩偶、水彩、扁平插画、黏土4类各写3条，保留用户提供的毛色和显著特征。
3. 每条写清单只宠物、头肩构图、1:1比例、纯净背景，并排除多肢、异常眼睛、文字水印。
4. 提供同一条提示词更换毛色和背景的示例；只产出文字，不许诺生成结果完全像原宠物。

## 产出

pet-avatar.md：12条宠物头像提示词及替换示例。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

4类各3条，12条都可独立复制，含毛色变量和使用说明。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
