# 宠物用品主图词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

宠物用品品类、核心卖点和产品外观颜色。缺少影响结果的信息先问用户。

## 执行步骤

1. 先确认产品是什么品类、什么颜色、面向猫还是狗，并提醒图片只用来做原创展示参考，不搬运别家实拍版权图。
2. 按居家猫窝布景、宠物食盆桌面、外出牵引道具、玩具互动特写4组生成共12套主图生图提示词，每套写清背景道具、光线角度和构图留白。
3. 给出2条直接可用的完整生图示例，排除动物毛发粘连、食盆歪斜变形和背景太花抢走产品焦点的写法。
4. 说明怎么按自己商品的实际颜色替换描述词，并附一条检查主体占比和左上角文字留白区的自查方法。

## 产出

pet-supply-main-image-prompts.md：12套宠物用品主图词、2条完整示例和留白检查。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套主图词分4组写明布景光线与留白，并附2条完整示例和检查方法。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
