# 萌宠短片分镜

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

宠物种类、外观特点和故事主题。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认宠物种类、外观和原创故事边界；只用用户有权使用的资料，隐私信息用代号。
2. 按居家玩耍、户外探索、温馨陪伴、节日布景4组各写3套，共12组提示词；每套规划3个镜头，写明场景、动作和景别。
3. 提供一组原创虚构萌宠示例；排除现有角色、真人仿冒、危险动作及不适合动物的场景。
4. 说明替换宠物特征、镜头顺序和画幅的方法，自查故事连贯与动物安全；只交付文本，不承诺生成视频。

## 产出

pet-vlog-storyboards.md：12组分镜提示词、原创示例和使用说明。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12组提示词分4类，每组含3个镜头，并附原创示例、排除要求及使用自查。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
