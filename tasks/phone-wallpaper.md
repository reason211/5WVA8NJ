# 手机壁纸提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

屏幕比例、配色和主题。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认手机屏幕比例和主题；用户不知道型号时以9:16作明确标注的通用建议，不称适配所有手机。
2. 设计自然、极简、几何、抽象渐变4组各3条，避免品牌标识和受保护角色。
3. 每条包含配色、9:16或用户比例、顶部时间区域留白、图标区低细节、不要文字水印。
4. 附锁屏预览与调整建议；只交付提示词，不擅自生成或下载素材。

## 产出

phone-wallpaper.md：12条竖屏提示词、比例与安全区建议。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12条竖屏提示词，每条含比例和留白说明，未承诺所有手机裁切一致。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
