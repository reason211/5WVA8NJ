# 人像微表情提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

角色大致年龄段、光线气氛和想要的表情状态。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认虚构角色年龄段、光线风格和用途，明确不仿冒任何真实人物或公众人物。
2. 按温和笑意、安静思索、意外惊诧和松弛疲惫4组生成12套提示词，细化眼神方向、眉眼和嘴角幅度。
3. 每套提供中英对照词和负向排除词，避开僵硬假笑、斗鸡眼和五官扭曲。
4. 说明如何把微表情词拼接到已有画风词里，并核对12套细节和负向词是否完整。

## 产出

portrait-micro-expression-prompts.md：12套人像微表情提示词、眼神嘴角细节和负向词。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

输出4组共12套微表情提示词，每套含五官细节词与负向排除词。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
