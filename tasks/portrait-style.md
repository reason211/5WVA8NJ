# 职业头像风格参考

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

背景色、服装和头像用途。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认用途为普通社交头像或视觉参考；不制作或伪造身份证件、资格凭证，不承诺考试报名合规。
2. 基于蓝、白、浅灰3种背景，各做正式和日常2种着装，共6条提示词。
3. 每条包含正面头肩构图、自然光、五官比例自然、背景干净；如用照片只使用本人授权素材，不加入证件编号或印章。
4. 说明生成脸部可能失真，应本人核对；只输出文字，正式证件照应遵从受理机构要求。

## 产出

portrait-style.md：6条职业头像提示词与身份用途限制说明。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

6条完整提示词；文件显著标注非证件用途，不含伪造凭证、审核包过等表述。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
