# 转正述职有条理

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

试用期记录、岗位职责和考核要求。缺少影响结果的信息先问用户。

## 执行步骤

1. 收集岗位、试用期起止、职责、任务记录、真实反馈与考核标准，隐藏敏感信息。
2. 规划10页：封面、岗位理解、目标、任务概览、案例两页、能力成长、不足、改进计划、总结。
3. 案例按背景、行动、结果梳理；无量化结果不杜撰，没有反馈不伪造上级评价。
4. 先出逐页稿，再用可用PPT技能生成可编辑PPTX；导出不可用则说明限制，只交逐页稿。
5. 核对10页、时间线、信息来源和排版；附3个可能被追问的问题供用户自己准备。

## 产出

probation-review.pptx及待补信息表；无导出能力时为逐页稿。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

10页初稿与3个追问，未虚构案例或评价，未承诺通过考核。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
