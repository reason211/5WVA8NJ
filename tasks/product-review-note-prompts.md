# 好物测评提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

测评物品名称、真实使用感受和缺点。缺少影响结果的信息先问用户。

## 执行步骤

1. 先让买家列出测评物品、预算档位和一两条真实缺点，强调内容只基于真实体验。
2. 按新旧款对比、同类横评、长期使用回访、避坑劝退4组，写出12套图文结构提示词。
3. 每套配一条原创开头示例，要求用口语短句，禁止使用极限夸大词和空洞套话。
4. 附上发布前自查清单，提醒去掉夸大承诺词并核对优缺点是不是都写全了。

## 产出

product-review-note-prompts.md：12套测评框架、标题句式和去硬广检查表。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套测评提示词分4组完成，每套含结构、示例开头和禁夸大说明。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
