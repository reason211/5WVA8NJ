# 项目计划讲清楚

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

项目目标、时间节点和人员分工。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问项目目标、范围、参与角色、起止时间、约束和已确认预算；区分事实和待讨论假设。
2. 组织12页：封面、背景、目标、范围、交付物、路线图、里程碑、分工、资源、风险、验收、下一步。
3. 依据输入生成里程碑与责任分工表，缺少负责人或工期标待定，不编造预算。
4. 先确认逻辑，再使用可用PPT技能导出可编辑PPTX；无法导出时交付逐页稿并说明限制。
5. 核对里程碑先后关系、范围外事项、风险应对与验收标准是否对应。

## 产出

project-plan.pptx、里程碑表和风险表；无导出能力时为逐页稿。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12页及2张表；假设与已确认内容分开，工期顺序无自相矛盾。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
