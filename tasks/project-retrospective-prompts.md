# 项目复盘指令

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

项目目标、过程记录和复盘重点。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认项目目标、复盘范围和原创整理边界；只用用户有权使用的资料，隐私信息用代号。
2. 按目标结果、过程节点、团队协作、后续改进4组各写4条，共16条可复制指令，要求区分事实、观察和待确认问题。
3. 提供一份明确标为虚构的项目填写示例；排除编造数据、臆测动机和未经核实的个人责任。
4. 说明如何填入记录并选择提问，自查结论依据、待确认项和建议适用条件，不自动通知或发送。

## 产出

project-retrospective-prompts.md：16条复盘指令、虚构示例和检查清单。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

16条指令分4组，含虚构示例、排除要求与事实核对清单。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
