# 大促主图提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

商品类目、主色调和促销节点。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认商品类目、主色和活动氛围，提醒只使用买家自有商品信息与原创布景，不套用受保护的品牌标识。
2. 按节日礼盒、清仓特惠、新品首发、爆款直降4组写出12套生图提示词，注明商品摆位和留白位置。
3. 每套配一组配色搭配建议和负面排除词，防止背景装饰盖过商品主体或生成乱码文字。
4. 整理出图后的裁剪留白检查表和文字区域替换提示，方便买家后期自己叠加上活动价格。

## 产出

promo-badge-image-prompts.md：12套大促氛围生图词、留白布局说明和配色示例。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。
