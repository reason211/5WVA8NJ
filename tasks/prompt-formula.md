# 万能提问公式

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

常用场景和一个想解决的问题。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问常用场景（写作、学习、办公、生活决策等）和一个当前想解决的问题。
2. 整理角色任务背景格式、分步追问、对比选择、反向检查、举例模仿、限制条件、费曼解释、清单拆解等12套提问模板，每套说明适用场景。
3. 每套给一个原创示例：原始提问和改写后的提问。
4. 用用户的真实问题按最合适的2套模板改写，并说明如何根据回答继续追问。

## 产出

prompt-formula.md：12套提问模板、原创示例和一次真实问题改写。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套模板各有适用场景和示例，并完成一次用户问题改写。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
