# 方案评审提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

一个准备推进的新想法和现有的资源限制条件。缺少影响结果的信息先问用户。

## 执行步骤

1. 先让买家说出想推什么事、手头有多少人和时间，提醒敏感业务数据和内部代号做脱敏处理。
2. 按内部小改优化、跨组协作立项、活动落地执行、老问题复盘重做4组，写出12套方案提纲提示词。
3. 每套给出一个原创办公流程优化示例，按背景问题、预期结果、具体步骤和风险预案写清。
4. 附上评审会上常被问到的5个追问问题和自查表，帮买家提前把漏洞补齐。

## 产出

proposal-review-prompts.md：12套提纲提示词、原创示例和评审问答预演表。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套评审提纲提示词分4组写全，每套都有原创示例和追问自查表。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
