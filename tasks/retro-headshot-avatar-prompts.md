# 复古胶片头像词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

角色形象描述（如发型、眼镜、穿搭颜色）。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认想要的虚拟人物形象、年代氛围和头像用途，提醒不模仿具体真人，涉及个人资料用泛化描述代替。
2. 按直闪日常、暖阳逆光、黑白暗房、彩色拍立得4组生成12套提示词，写明面部居中与头部留白比例。
3. 每套给出一个原创角色示例，并排除过度噪点、面部阴影遮挡和边缘裁切太满的问题。
4. 附上头像圆框裁切检查要点和表情微调词表，方便买家快速挑出最顺眼的一版。

## 产出

retro-headshot-avatar-prompts.md：12套胶片大头照提示词、构图比例和配色说明。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。
