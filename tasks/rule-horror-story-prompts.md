# 规则怪谈小说词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

想写的日常场景、主角身份和篇幅计划。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认想写的生活场景、主角身份和预计字数，所有地名、公司和人物都用架空虚构名字。
2. 按校园宿舍、深夜值班、社区物业、列车出行4组生成共12套规则怪谈提示词，每套写明表面守则、隐藏冲突和破局条件。
3. 给出1套含6条守则的原创设定与开篇示例，写明排除堆砌血腥词、规则互相打架和强行吓唬人的写法。
4. 说明怎么把自己的场景想法填进模板让AI写出正文，并附一条核对前后守则和结局能不能圆上的检查方法。

## 产出

rule-horror-story-prompts.md：12套规则怪谈提示词、1套规则清单示例与自查建议。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套提示词分4组写清守则与破局条件，并附1套原创设定示例和检查方法。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
