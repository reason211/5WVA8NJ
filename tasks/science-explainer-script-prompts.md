# 科普脚本词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

一个科普冷知识主题、目标观众和单条视频时长。缺少影响结果的信息先问用户。

## 执行步骤

1. 先确认科普话题、观众基础和视频时长，要求用可核实的公开常识起稿，不编造假实验或假数据。
2. 按反常识提问、身边小实验、类比拆解和误区纠正4组，写出12套科普短视频脚本提示词，标出每段秒数。
3. 每套给一段口播脚本示例，标出必须删掉的书面长句，提醒把术语换成生活里的打比方。
4. 附上事实核查清单和口播念读检查法，确保念出来顺嘴且结论经得起查。

## 产出

science-explainer-script-prompts.md：12套科普脚本框架、口播示例和核查清单。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套科普脚本提示词分4组并带口播示例，含事实核查与念读检查法。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
