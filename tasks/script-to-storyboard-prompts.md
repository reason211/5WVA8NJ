# 连贯分镜提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

一段原创短剧剧本或故事梗概。缺少影响结果的信息先问用户。

## 执行步骤

1. 先核对买家提供的剧本属于原创或有权使用的内容，涉及真实人名或地点先换成代号。
2. 按固定角色卡、室内对话、追逐转场、道具特写4组生成12套分镜提示词，写清景别、运镜和锚点词。
3. 用一段原创小片段演示如何把剧本拆成3个连续镜头，标出必须保留的服装和道具细节，排除突然变装。
4. 附上分镜生成后的连贯性自查表和常见穿帮修正口令，方便买家跑视频模型时一次对齐。

## 产出

script-to-storyboard-prompts.md：12套剧本转分镜指令、锚点锁定表和一段示范。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套分镜指令包含连贯锚点写法，并附3镜头示范。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
