# 自我介绍两版稿

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

目标岗位、真实经历和表达风格。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认目标岗位、真实经历和希望强调的2个优势，缺少案例先追问。
2. 按目前身份、相关能力、真实案例、求职动机写两版，避免空泛自夸。
3. 60秒稿约180至240中文字、90秒稿约270至360中文字；按语速估算并标明并非准确时长。
4. 逐项对照原素材验证事实，附试读后删减或加长建议。

## 产出

self-introduction.md：两版口述稿、事实对应和删减建议。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

两版稿与字数统计、事实对应表齐全；不虚构经历，时长标注为试读估算。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
