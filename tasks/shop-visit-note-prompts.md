# 探店打卡提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

店铺类型、实拍亮点、真实感受和消费区间。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认探店品类、实际消费体验、推荐或不推荐的点；所有描述须来自买家真实经历，不虚构排队时长或门店信息，隐私信息打码。
2. 按咖啡甜品店、烟火气小馆、展馆书店、周末新店踩点4组生成共12套图文提示词，每套包括开头切入、细节描写顺序和结尾提醒。
3. 给出2套填好细节的原创笔记示范，排除夸张感叹词、空洞夸赞和一眼像广告的硬广句式。
4. 说明如何把手机里记下的零散感受直接丢给AI整理，并附上一条检查错别字、人均价格和地址是否准确的清单。

## 产出

shop-visit-note-prompts.md：12套探店文案提示词、标题公式示例与发布自查。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套探店提示词分4组并含写作顺序，附带2套原创示范和自查清单。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
