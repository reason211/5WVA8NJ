# 口语对练词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

想练的语种、当前水平和最常遇到的说话场景。缺少影响结果的信息先问用户。

## 执行步骤

1. 先问清楚想练的语种、目前能说多少以及每天练习几分钟，只用常见生活场景，不涉及涉密工作内容。
2. 按出门旅行、职场开会、朋友闲聊和表达观点4组，写出12套口语对练提示词，设定好AI的回复长度。
3. 每套配一段两轮对话示例，标出“一次只纠一个错”的限制词，避免AI长篇大论打击开口信心。
4. 附上难度调节开关和每日复盘表，买家直接复制进对话就能按自己节奏开练。

## 产出

spoken-language-practice-prompts.md：12套情景陪练指令、纠错设定和对话示例。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套口语对练提示词分4组且各有对话示例，含难度调节与纠错设定。
