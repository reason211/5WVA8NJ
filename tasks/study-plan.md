# 30天学习安排

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

学习目标、当前基础和每日可用时间。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问具体目标、基础、开始日期、资源来源、工作日和周末可用时间，不把未知基础假设成零。
2. 按诊断、学习、练习、复习分阶段，分配30个连续日期，安排每周复盘与缓冲日。
3. 每行列日期、任务、预计分钟、完成标准、复习对象和勾选状态，每日总分钟不超过用户可用时间。
4. 资源只使用用户提供或合法公开渠道；不复制付费课程或提供考试作弊内容。
5. 检查时间总量与日期连续性，给出落后一天时的调整规则，不承诺达到特定分数。

## 产出

study-plan.csv与weekly-review.md：30天计划、每周复盘问题。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

30个有效连续日期，每天有可检查产出，时间不超预算，包含复习与缓冲。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
