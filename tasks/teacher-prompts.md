# 教师AI指令

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

学科、年级、课题和班级情况。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问学科、年级、课题、课时和班级情况；学生姓名等信息用代号，不收集隐私。
2. 整理教案、导入设计、课堂提问、分层作业、试题讲评、学生评语、家长通知、班会方案、教学反思、说课稿10类指令。
3. 按用户课题生成一份教案初稿，含教学目标、重难点、教学流程、板书和作业，知识点标注需老师复核。
4. 附评语模板（优点、建议、鼓励）和家长通知模板，语气得体，避免标签化评价。

## 产出

teacher-prompts.md：10类教师指令、一份教案初稿与评语模板。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

10类指令齐全，教案初稿结构完整，需复核处已标注，学生信息未实名。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
