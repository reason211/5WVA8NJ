# AI文字冒险

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

喜欢的题材和游戏难度。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问喜欢的题材（修仙、悬疑、末日、校园、宫廷、科幻等）和难度；只写原创世界观，不使用现有影视、游戏或小说人物。
2. 为6个剧本各写开局指令：世界观、玩家身份、目标、可用行动、数值（体力、金钱、好感等）和每回合输出格式。
3. 写清规则：AI只扮演世界与配角，每回合给3个选项并允许自由输入，不替玩家做决定；内容健康，不含血腥低俗。
4. 附存档模板（当前数值、已发生事件）和读档指令，方便下次继续。

## 产出

text-adventure.md：6个剧本的开局指令、规则说明与存读档模板。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

6个原创剧本各有开局指令、规则和存读档模板，复制即可开始。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
