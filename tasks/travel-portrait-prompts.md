# 旅行打卡人像词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

旅行地点类型、人物穿搭风格和想拍的时段。缺少影响结果的信息先问用户。

## 执行步骤

1. 先询问目的地环境、穿搭颜色和打算上午还是傍晚拍，只做原创动作与构图描述，严禁填写明星姓名或他人隐私照片。
2. 按海边日落、古城街巷、山野远景、咖啡街角4组生成共12套旅行人像提示词，每套写明机位高低、人物朝向、衣裙动态和阳光角度。
3. 提供2条能直接生图或照着摆拍的完整示例，排除僵硬站桩比剪刀手、人脸逆光全黑和路人乱入抢镜头的构图。
4. 说明怎么根据当地阴天或晴天调整光线词，并附一条检查地平线别斜、人物比例自然和背景别太杂的自查方法。

## 产出

travel-portrait-prompts.md：12套旅行人像提示词、2条完整机位示例与防游客照检查。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套构图词分4组写明机位光线与动作，并附2条完整示例和自查方法。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
