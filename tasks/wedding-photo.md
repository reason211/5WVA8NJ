# AI婚纱照提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

两人的清晰照片和喜欢的风格。缺少影响结果的信息先问用户。

## 执行步骤

1. 询问喜欢的风格、服装偏好和照片情况；只使用双方本人同意使用的照片。
2. 按中式、西式教堂、海边旅拍、城市夜景、森系草坪5组各写4条提示词，含服装、场景、姿势、光线和构图，保持两人面部特征。
3. 每条附排除要求（不改五官、不替换成他人面孔、无文字水印）和推荐画面比例。
4. 说明照片要求和在可用生图工具中的使用步骤，提示生图可能另耗积分。

## 产出

wedding-photo.md：20条婚纱照提示词、照片要求和使用步骤。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

20条提示词分5组，均含排除要求，并附照片要求和使用步骤。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
