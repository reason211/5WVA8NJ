# 周报提炼提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

本周做过的琐碎工作清单和几个关键结果数字。缺少影响结果的信息先问用户。

## 执行步骤

1. 先让买家贴出本周做过的流水账工作记录，提醒把公司内部项目名、客户和同事名字换成代号。
2. 按日常执行岗、项目推进岗、客服支持岗、下周计划与风险4组，写出12套周报提炼提示词。
3. 每套附一个改写前后的原创示例，要求用短句先说结果再写动作，禁止空泛大词和无依据的数字。
4. 附上汇报前核对清单，提醒买家逐条检查时间、数据和下周安排是否和实际情况对得上。

## 产出

weekly-report-polish-prompts.md：12套汇报提示词、改写前后示例和防编造自查项。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套周报提示词分4组写全，每套都有改写前后示例和禁编造约束。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
