# 女装主图词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

服装款式、面料颜色和店铺平时主打的客群风格。缺少影响结果的信息先问用户。

## 执行步骤

1. 先确认衣服品类、颜色版型和拍摄季节，只用通用虚拟模特描述，不使用真人明星或网红特征。
2. 按都市通勤、咖啡馆街拍、慵懒居家和周末出游4组，写出12套女装上身生图提示词，突出面料垂感和剪裁。
3. 每套附一组完整生图示例，标出容易糊掉衣服细节的词并给出替换写法，避免背景抢镜。
4. 附上服装颜色、面料和站姿的替换词表，方便买家按自家新款直接改词出图。

## 产出

womenswear-outfit-image-prompts.md：12套女装场景生图词、面料光线词库和示例。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。
