# SOP手册指令

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

岗位名称、日常要做的事和几个容易出错的卡点（敏感信息请用代号）。缺少影响结果的信息先问用户。

## 执行步骤

1. 先核对岗位职责、输入材料和权限边界，提醒买家把真实姓名、客户数据和密码全换成代号。
2. 按日常例行、突发异常、交接核对和工具操作4个模块，搭建SOP提示词框架并按买家资料生成初稿。
3. 补一份原创客服或行政岗SOP完整示例，标出常见废话，要求每一步都写清动作、工具和完成标准。
4. 附上适用范围检查表和版本更新栏模板，方便买家拿到部门里直接微调定稿。

## 产出

work-sop-manual-prompts.md：岗位SOP编写指令模板、一份完整示例和自检表。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

生成含触发条件、步骤和异常处理的SOP初稿，另附示例与检查表。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
