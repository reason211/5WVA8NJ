# 武侠打斗分镜词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

对决双方人数、兵器类型和打斗场景氛围。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认人物兵器、场景是竹林客栈还是悬崖高台，人物与招式全部原创命名，不用现有小说或影视里的角色名。
2. 按对峙蓄力、近身交锋、腾空追击、收招定格4组生成共12套打斗分镜提示词，每套写明景别、运镜方向、动作节拍和衣袂尘土细节。
3. 给出1组由3个镜头接起来的完整竹林过招示例，排除兵器半空消失、人物穿模和镜头乱切让人晕头的描述。
4. 说明怎么调慢动作时长和光影反差来控制画面节奏，并附一条检查手部握剑姿势与人物左右站位的核对办法。

## 产出

wuxia-action-storyboard-prompts.md：12套打斗分镜提示词、1组3镜头连贯示例与排查方法。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套分镜词分4组写明运镜与动作节拍，并附1组3镜头连贯示例。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
