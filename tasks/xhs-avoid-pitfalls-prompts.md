# 小红书避坑攻略词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

要分享的主题（如租房/出游/买家电）和几个真实注意点。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认分享领域和读者人群，要求所有案例脱敏处理，只用真实经历或通用常识，不夸大效果。
2. 按出行准备、居家选购、办事流程和新手常见误区4组生成12套提示词，写清痛点引入和对照建议。
3. 每套给1个原创开头句和配图文字建议，并排除制造焦虑和绝对化用词。
4. 说明如何把自己的流水账笔记转成清单图文，并检查12套框架和示例是否齐全。

## 产出

xhs-avoid-pitfalls-prompts.md：12套避坑图文提示词、封面标题句式和排版建议。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

输出4组共12套避坑图文提示词，每套含开头示例和用词排除提醒。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
