# 经验笔记提示词

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

你的分享领域和一两个真实经历片段。缺少影响结果的信息先问用户。

## 执行步骤

1. 确认买家分享的主题领域和真实经历素材，约定只写本人有权发布的经验，隐私细节用化名或泛称。
2. 按走了弯路、低成本习惯、工具对比、周末复盘4组写出12套提示词，每套写明开头钩子和正文分段。
3. 每套给出一段真人语气改写示例，明确排除生硬喊口号、过度排比和营销推销腔。
4. 整理成文后的读顺检查清单和标签搭配建议，让笔记写完直接能发、读着不别扭。

## 产出

xhs-experience-note-prompts.md：12套经验分享笔记指令、开头示例和去广告味检查表。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

12套笔记框架口语自然，含去营销味自查清单。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
