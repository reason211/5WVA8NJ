# 图文初稿3篇

执行前读取仓库根目录 README.md 的「任务执行规则」，并遵守全部安全边界；读取失败先停下说明。

## 输入

真实体验、读者画像和主题。缺少影响结果的信息先问用户。

## 执行步骤

1. 收集真实体验、主题、目标读者和可验证产品信息；没有亲身体验时写资料型内容，不能伪装成亲测。
2. 用教程、清单、复盘3种结构各写1篇，每篇约300至500中文字，分别提供3个不过度夸张的标题。
3. 每篇提供3至5条配图构思和相关标签；不使用站外联系方式、虚假测评或收益承诺。
4. 检查数字与素材一致，标注广告合作或AI辅助内容需按平台规则处理；只交稿不发布、不点赞评论。

## 产出

xhs-notes.md：3篇笔记、每篇3个标题、配图建议和自检项。写入用户指定的新输出目录，文件重名时另起名，不覆盖原件。

## 验收

3篇结构不同，9个标题，配图建议和自检项完整；无捏造体验或自动发布。

最终报告实际生成的文件路径、检查结果、未完成项及限制。没有生成或没有验证的内容不能写成已完成。
